# DEM 窗口、地形与完整方法基准

使用 P13-01 的 EPSG:32650 米制 DEM。S/M/L 分别为 512、2,048、8,192 像元见方，单波段 Float32，像元边长 10 m，NoData 为 -9999，输入块为 256 × 256。每 128 × 128 个像元含一个独立 NoData。分析范围内缩一个像元，Horn 计算邻域半径为一像元。 [输入配方](../datasets/raster.yaml) · [共同协议](../README.md)

```bash
python scripts/bench/run_raster.py --profile benchmarks/datasets/raster.yaml
```

默认对 S、M、L 依次测两个缓存状态和两类负载。每组有两轮预热和五轮测量。可用 `--tiers S M`、`--cache process_cold warm`、`--workload tools method` 选择本次调用范围。`--pilot` 每组只运行一次并明确标为先导。`--input-root /path/to/inputs` 复用已有 P13-01 输入，目录按 `S/manifest.json` 等组织。未给出时由正式生成器在新工作区创建。`--output` 指向一个新目录，保存 `trials.jsonl`、`report.json`、每轮运行文件和失败日志。

## 独立工具

读取三种像元窗口，分别跨过内部数据块边界、贴合源右下边缘、穿过一个 NoData 邻域。实际调用 V1 的 `read_raster_window` 并逐像元核对高程、掩膜、NoData 和窗口 transform。外扩调用 V1 的 `plan_dem_windows`，核对裁剪窗和完整外扩窗。坡度度数、坡度百分比和坡向各调用生产 API 一次，输出和逐像元验算单独保留。

解析平面每 10 m 东向上升 10 m，参考坡度 45°、100%，下坡坡向 270°。源外缘无完整邻域，独立 NoData 的输出掩膜是 3 × 3。每档有效数为 `(n-2)²-9×(n/128)²`，角度和百分比允许 1e-5 绝对误差，分类和掩膜精确匹配。

## 完整方法

使用 V1 API 注册资产、创建草稿、确认、提交 `dem-terrain-analysis@1`，等待运行及检查持久化。记录七步实际执行及 P13-02 旁路遥测。正式结果逐像元校验裁回的坡度和 45° 分类。等积面积独立计算 EPSG:6933 下 AOI 外环面积减各 NoData 邻域空洞面积。环边从 50 m 加密到 25 m，短边每边至少 16 段。共有边在面积求和中抵消。独立积分两次的相对容差为 1e-8、绝对容差为 0.02 m²。正式比较相对容差为 2e-7、绝对容差为 0.02 m²。

端到端墙钟从提交确认后的计划到 API 观测到持久终态，轮询间隔为 0.2 s。初始化、资产登记、建草稿及确认、原始输入生成、指纹和独立验算另计。完整方法的 CPU、存储 I/O 和 RSS 使用 P13-02 口径。独立工具记录 Python 进程 `getrusage` CPU 差及 `/proc/self/io` I/O 差，按约 50 ms 采样 RSS 与文件大小。工具冷组每个操作单独启动 Python 进程，分别记录含解释器启动耗时和 API 执行耗时。热组保留 Python 进程或服务，预读该轮输入并使用新任务和结果文件。两组的操作系统页缓存均标为未控制。

吞吐按每轮处理的源网格像元或指定窗口像元除以测量墙钟。邻域外扩仅生成窗口记录，吞吐字段留空。暂存目录的峰值按 inode 去重，单列点号开头的生产临时目录与工作区文件总峰值，约 50 ms 采样可能漏掉短峰。返回码为 0 表示本次选择的组通过，1 表示启动、运行或比较失败。原始 JSONL 保留失败和未完整的组，统计以正式轮次的正确样本为基础。 [性能证据](../../docs/round2/performance/p13-04.md)
