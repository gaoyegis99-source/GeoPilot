# GeoPilot 多规模性能基准协议 v1

[总清单](manifest.yaml) 声明规模、资源指标和重复规则。P12-11 固定样本配方、量测边界和独立验算规则。P13-01 根据配方生成各档数据，P13-02 接入 run/step 遥测，P13-03/04 执行测量。当前证据覆盖清单、V1 微型样本生成和真实方法入口。

测量开始前在新目录生成输入，仅使用仓库内合成坐标、像元和产品 XML 模板。每个文件记录 SHA-256、长度和逻辑摘要。栅格摘要记录 CRS、transform、尺寸、类型、有效掩膜和像元摘要；矢量摘要记录按原始 ID 排序的属性、坐标和图层计数。GeoPackage 日期和页布局可能随构建环境变化，跨环境比较同时核对逻辑摘要。组内各轮复用相同字节，首尾分别校验源文件。

## 矢量

[矢量配置](datasets/vector.yaml) 采用米制 EPSG:32650 和 GPKG。每个行列单元以 (origin_east_m + col × pitch, origin_north_m + row × pitch) 为原点。道路及空间关系模板以参考原点 (500000, 4400000) 平移到各单元。单元相距 4,000 m，分析范围 2,000 m，固定 500 m 外扩。平移保留道路边界、孔洞和精确接触点，原始 ID 增加行列前缀。每条道路按档位顶点数等距共线加点，另加固定长度 ASCII 属性。 [道路参考](../tests/fixtures/vector/README.md) · [关系参考](../tests/fixtures/vector/t13/README.md)

- 道路筛选、关系判断、裁回和计数分别保留摘要。候选道路及裁回前后的精确 ID 集合按单元复制，西区、东区和未归属计数逐单元核对。intersects 每单元应选 6 个唯一目标，within 选 5 个。用单线离散圆端参考核查缓冲几何及包络，容差沿用 V1 独立参考。
- 点、线、面 T13 孔洞样本分别复验 intersects 与 within 的原始 ID、裁回几何及保留长度或面积。选择谓词在裁回前执行。
- 面归属基准以 V1 T14 的矩形、含孔范围和三种规则参考为模板，使用原 EPSG:6933 等积坐标生成同档数量的隔离单元。保留同单元内重复来源 ID、重叠片段、边界无面积接触和不覆盖区域。逐单元检查 6 个唯一对象、2,200 m² 总面积和 300 m² 未覆盖面积，并对照三种规则的逐 ID 和分区明细。 [T14 几何与参考](../tests/gis/test_source_feature_identity.py)

## DEM 与栅格

[栅格配置](datasets/raster.yaml) 采用北向上 EPSG:32650、10 m 像元、Float32 单波段 GeoTIFF 和 256 × 256 数据块。输入高程为 100 + 10 × column 米，NoData 为 -9999。按档位在每个 128 × 128 周期中心索引 (64 + 128r, 64 + 128c) 写入孤立 NoData。AOI 由完整输入边界内缩一个像元，Horn 用一个像元邻域。窗口测试包含内部块边、源边和 NoData 邻域。输入可按块写入同样像元，保持固定块布局。

独立参考使用解析平面。全邻域有效的位置输出坡度 45° 或 100%，下坡方向 270°。一个 NoData 使对应 3 × 3 邻域的输出为 NoData，掩膜按中心点独立构造。有效输出数为 (n − 2)² − 9 × (n / 128)²。同时比较裁回坐标、网格和有效像元，角度绝对容差 1e-5°。完整方法的 45° 分类仍逐像元核查。 [V1 微型栅格模板](../tests/fixtures/raster/README.md)

## 双日期遥感

[遥感配置](datasets/remote-sensing.yaml) 采用 EPSG:32632。第一期合成 Landsat 8 L2SP C2 02，30 m 网格 n × n，四波段 QA_PIXEL、SR_B5、QA_RADSAT、SR_B4。第二期合成 Sentinel-2 L2A 05.11，10 m 网格 (3n + 2) × (3n + 2)，左上相对第一期向西和北偏 7 m。第二期波段为 SCL、B08、B04，SCL 从 20 m 网格最近邻展开。两期使用 UInt16，并沿用原有产品 XML 字段、标签和掩膜约定。 [V1 配对模板](../tests/methods/remote_sensing_fixtures.py) · [合成 XML 模板](../tests/remote_sensing/product_fixtures.py)

按首期列号余数 col % 6 生成六个等宽相位，依次为增加、减少、不变、首期云、次期云、首期红光填充。首期红光 DN 10,000，减少相位近红外 20,000，其他相位 10,000。次期红光 2,250，不变相位近红外 2,250，其他相位 4,750。首期云用 QA_PIXEL 位 3，次期云用 SCL 9，其他 SCL 为 4，首期红光填充 DN 为 0。各次期 10 m 像元和 20 m SCL 像元用像元中心投影到首期列确定相位。AOI 为首期矩形。

以最近邻对齐首期网格，次期列索引为 floor((30 × col + 15 + offset) / 10)，行索引同理。原生 SCL 使用除数 20。独立以 NDVI = (NIR−Red)/(NIR+Red) 验算，Landsat 缩放为 0.0000275 × DN − 0.2，Sentinel 为 (DN − 1000)/10000。前三相位差值约 0.5、-0.14705882、0，阈值 0.1，后 3 个相位为 NoData。每相位有 n² / 6 个像元，公共有效 n² / 2。核对 QA 掩膜、对齐 transform、变化方向及类别，连续值容差 1e-6。面积参考依据有效像元边界投影至 EPSG:6933 后独立累计。保留 V1 零分母、窄 AOI 和双线性路径小样本作正确性检查。

## 完整方法

[方法配置](datasets/method.yaml) 映射三个规模族到仓库内的精确方法版本。沿用真实资产登记、分析草案、确认、run、step、check 和 artifact 流程。道路 v2 使用 EPSG:32650 局部投影、500 m、intersects、中心归属、边界并列不归属、计数和裁回 AOI。DEM v1 使用 1 波段、米、坡度度数、z-factor 1、45° 分类和 EPSG:6933。遥感 v1 使用上述产品配置、最近邻、阈值 0.1 和 EPSG:6933。

数据生成、服务初始化和资产登记单列。端到端墙钟从提交确认方案到持久化最终运行和检查状态；另记排队、逐步执行和检查开销。独立工具运行和完整方法分组报告。每轮使用新 run ID 和输出目录，维持单活动运行。资源记录绑定 run/step、版本、参数摘要和输入哈希。核对全部 7/7/8 个步骤、检查状态、输出角色和来源，再执行对应独立几何和数值断言。

## 资源采样与统计

每次报告包含 commit、清单 SHA-256、OS 和内核、CPU 型号及逻辑/物理核数、核配额和亲和、RAM 与 swap、容器限制、存储介质和文件系统、Python、QGIS、GDAL（QGIS 与 Python 侧分别记录）、PROJ 与数据版本、GEOS、Rasterio、Pyogrio、NumPy、运行命令、工具版本、线程和缓存参数。比较使用同一硬件和配额，记录后台负载及配置变化。每轮测量期间仅运行一个 GeoPilot 负载。

每个规模、方法和缓存状态至少 5 次计入测量。先做 2 次独立预热，样本另标 warmup。冷、热分别固定顺序并汇总。process_cold 重新启动执行进程并使用新项目与运行目录，OS 页缓存标为未控制。warm 预读相同输入并保留服务进程，仍创建独立运行。OS 冷缓存标签只用于有独立证据的隔离实验。报告原始记录、通过数、失败数、缺失数、median 与 nearest-rank P95，后者从小到大取第 ceil(0.95 × n) 项。5 个样本时 P95 等于最大值。少于 3 个正确样本的组不产生性能结论。

| 字段 | 单位与边界 |
|---|---|
| wall_ns | 单调时钟，逐 step 从派发到子进程退出，run 从提交到最终持久状态。另记排队与检查 |
| cpu_ns | 进程树用户加系统 CPU 时间，记录子进程归属；容器执行从容器 cgroup 读累计差 |
| peak_rss_bytes | 进程树同时驻留的最大采样值，记录间隔和可能漏峰；容器内存峰值另列，语义为 cgroup 总内存 |
| disk_read_bytes、disk_write_bytes | Linux 存储 I/O 起止差。进程树使用 /proc 计数，容器使用 cgroup io.stat |
| peak_temp_bytes | 独立运行目录的临时文件峰值，按 inode 去重，报告间隔、保留与清理结果 |
| input_bytes、output_bytes | 实际输入文件及正式产物的字节和，硬链接去重；逻辑栅格裸数据量另列 |

缺少权限或进程退出前无法取得的资源值标为 unavailable，记录原因。每轮保留退出码、错误、正确性断言和日志。仅以正确性口径相同的成功测量比较吞吐或容量。P13-02 以对照负载量测采样开销，限制目录遍历和采样成本，保持派发、取消及退出路径通畅。

## P12 清单与微型样本复核

从原型目录执行以下命令。

    python scripts/bench/validate_benchmark_manifest.py
    python scripts/bench/validate_benchmark_manifest.py --probe
    python -m pytest -q tests/benchmarks/test_benchmark_manifest.py

校验器只读取清单、项目配置与 V1 参考，返回 S/M/L 尺寸和派生计数。可选探测在独立临时目录调用 V1 构造器生成道路、T13、DEM 和两期产品，再打开文件检查图层数、网格、分辨率、CRS 和有效像元，记录实际 SHA-256。临时目录自动清理。微型样本证明格式和入口可用，S/M/L 批量生成和性能实测留待 P13。
