## 阶段验收规则

1. 本阶段所有标记为 MUST 的原子任务均为 ACCEPTED，或经主控明确记录为本轮不适用。
2. 阶段测试报告列出 PASS、FAIL、NOT_RUN；不得隐藏未执行项。
3. 所有跨模块接口变更已更新契约和调用方测试。
4. 真实 GIS 能力不得只凭 Mock 通过。
5. 主控签署阶段验收记录后，才允许放行依赖阶段。

## 阶段真实运行

V2.0 §12.3.4 要求在原子任务交付外完成真实道路七步、复算和第二项方法。主控单独核对相应工具契约和进程证据，再使用 P3-08 至 P3-10 产出的编译与确认能力执行阶段用例。初版道路用 P0 点对象样本、已确认的局部投影和明确的计数归属。完整空间关系与跨界面积验收按 P6 执行。

先分别验证 QGIS 面外扩、道路取数、缓冲、点关系和属性筛选，以及 Python 测量输入准备、裁回和分区计数。阶段运行通过同一套目录、草稿、确认和编译入口连接这些工具。T07、T08 必须直接核对候选道路，同时复核选中点、裁回后 ID 和分区计数。
