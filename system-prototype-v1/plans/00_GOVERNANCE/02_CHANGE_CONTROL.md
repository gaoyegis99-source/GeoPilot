# 设计与接口变更控制

任何偏离 GeoPilot V2.0 的变更必须先提案，不得由执行 Agent 自行决定。

变更提案至少包含：
1. 原设计章节/需求编号。
2. 当前代码或环境事实。
3. 为什么原设计无法直接实现。
4. 受影响模块、任务、API、数据库和测试。
5. 至少一个替代方案及代价。
6. 推荐方案和回滚方式。

主控批准后更新：
- `01_ARCHITECTURE/` 对应契约；
- 受影响任务文件；
- `06_PROGRESS/CHANGELOG.md`；
- 相关测试和验收标准。

数据库 schema、公共 Pydantic 模型、API 请求/响应、状态枚举和工作目录结构均视为共享契约。修改这些内容必须先冻结新版本，再由唯一责任 Agent 实施。
