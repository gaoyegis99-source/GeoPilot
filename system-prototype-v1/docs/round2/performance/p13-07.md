遥感 S 的真实样本记录了一次 SQLite 锁冲突。主控以数据库副本和独占写锁复现子进程结果已写入、父进程取消轮询抛出 `SQLITE_BUSY` 的路径。D 在独立候选 `968e97b76591433c83a2184815035660294c3c75` 中修复，集成提交为 `71ae95d6fbe3f58348743f5697d235675beee790`。 [遥感 S 原始证据](p13-05-raster-s.md)
