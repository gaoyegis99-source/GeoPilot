# P13-06 DEM 中间面积报告复用

主控验收通过。A 实现有界缓存存储并独立复验运行时变更，D 实现来源契约和过程检查，主控接入运行链、复跑 GIS 和校验归档。源码提交为 `55e34e04ccef59fb1d52f809dfda637e1ab620d4`。

`--step-cache` 和 `create_local_app(..., enable_step_cache=True)` 可启用本机试点，默认关闭。试点覆盖 DEM 地形分析 v1 的等积面积步骤，输入为内置阈值工具产生的无伴随文件单 TIFF，输出为不超过 64 KiB 的 JSON。缓存随服务会话创建，正常退出时清理。进程被强制终止时可能留下独立临时目录，后续会话使用新目录。

## 失效与复验

缓存键覆盖语义方案快照、方法和工具精确版本、实际工具契约及绑定、步骤参数、输入内容摘要和本机运行身份。运行身份包括 Python 安装、源码及实际启动环境。外部 GIS 数据目录、未知可用 Python 导入路径和站点启动扩展触发普通计算。A 的独立探针用相同请求和 TIFF 让两个子进程成功退出，`src/affine.py` 覆盖引起 93,178.82 平方米的差异。当前守卫拒绝该次复用，移除覆盖后恢复基准运行身份。 [预验与其他反例](p13-06-preflight.md)

缓存仅登记执行和检查均通过的真实计算。命中时校验来源步骤、参数、输入和原成果摘要，核对报告内容，再通过运行目录租约发布本次成果。过程检查验证本次产物、来源和缓存日志，正常的成果规则继续运行。中断后复检使用同一份本次成果。损坏条目或无法验证的来源会走普通计算，通过后可覆盖损坏条目。日志及 `StepResult.reuse` 记录来源运行、步骤、缓存键和成果摘要。复用步骤的 `exit_code` 为 `null`。普通执行保留原序列化。回滚时停止服务并移除启动参数即可关闭复用。含复用记录的历史数据库需要支持 `StepResult.reuse` 的版本读取。
