## 执行命令与复现

从原型根目录运行。容器行在容器中使用系统 Python 3.12.3、Node 22.23.1 和原生 CLI。浏览器行运行时两个本机服务按启动说明使用不同的临时回环端口。完整启动参数在原始报告内。

    PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/install-check/run_matrix.py \
      --label ubuntu-20.04-host --ref 8bf0e15 \
      --qgis-process .environments/qgis-deb/qgis_process \
      --output docs/round2/deployment/p16-02-ubuntu20
    python3 scripts/install-check/run_matrix.py \
      --label ubuntu-24.04-native-qgis-container --ref 8bf0e15 \
      --qgis-process /usr/bin/qgis_process --output /evidence/p16-02-ubuntu24
    GEOPILOT_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
      node scripts/install-check/check_browser.mjs http://127.0.0.1:5173/
    PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONDONTWRITEBYTECODE=1 \
      .venv/bin/python -m pytest -q -p no:cacheprovider tests/diagnostics \
      --junitxml=docs/round2/deployment/p16-02-junit.xml

交付 `scripts/install-check/run_matrix.py`、`scripts/install-check/check_browser.mjs`、`tests/diagnostics/test_install_matrix.py`、[部署矩阵](../../deployment/install-matrix.md) 及本报告列出的原始证据。生产服务接口、配置、数据与依赖未改。其他浏览器、平台和跨主机部署均未测。撤销本项集成提交可移除验证脚本、测试、文档及证据。
