# P15-06 GIS 候选代码隔离契约

试点为已登记固定样例的单波段高程阈值统计。可信宿主按样例清单检查 GeoTIFF 指纹、范围、波段和 NoData。候选代码接收有上限的数字列表和阈值，返回有效像元数及达标像元数。核验以独立手算参考和真实 GeoTIFF 为依据。只有确认等积网格和米单位时，可信宿主才按像元面积换算面积。

## 候选与结果

模型或维护者提交候选源码文本，运行器将它和派生样例写入专用临时目录。每次只接收一个固定签名的 Python 函数，先检查源码长度、AST 节点数量和声明范围。代码只需有限的数字、布尔值、列表、字典、局部变量和基本算术、比较、迭代。语法检查拒绝导入、属性访问、动态执行、文件访问、进程、套接字和超出契约的调用。模型请求只描述输入和输出的类型及约束，样例像元和源文件路径留在本机。

可信包装器校验返回 JSON 及整数边界，并对照独立参考。通过的报告含候选摘要、样例摘要、运行环境、资源上限、退出结果和复核状态。通过仅进入 `REVIEW_REQUIRED`。维护者可以审阅源码和样例报告。若后续收录正式工具，仍须按既有 ToolContract、方法、独立参考、隔离试跑和人工发布流程审核。

## 运行边界

以内容固定的本机容器镜像运行，拉取策略为 `never`。容器使用非特权用户、只读根文件系统、禁用网络、清除 capabilities、禁止提权，并限制内存、CPU、进程数、描述符和运行时间。挂载仅包含候选源码、可信包装器及派生样例的专用只读临时目录。容器进程启动时使用明确的环境变量集合。Docker 客户端和用户目录留在宿主。

用已有进程捕获记录退出和超时。超时、异常或取消时终止本次创建的容器，核验其已退出并清理。对候选输出设置大小和类型约束。宿主以固定资源参数构建命令，镜像、挂载点、工作目录和进程参数由本地工具控制。容器不可用时返回明确的隔离不可用结果。

## 验收样例

正例覆盖实际栅格、NoData、阈值边界及独立参考。反例覆盖文件、网络、凭据和不受支持的语法，确认静态拒绝发生于子进程启动之前。用合规语法的资源压力样例确认内存限制、超时、容器终止和清理。单独核对试跑前后正式工具目录、项目数据库及原始样例摘要。
