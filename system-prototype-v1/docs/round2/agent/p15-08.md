## 风险与适用范围

固定 Mock 可检测请求、解析和防越权契约漂移。本机实测是三个英语合成任务的单次采样，覆盖两个方法和一个出站负例。目标词组匹配衡量本评估定义的意图要素。结果可用于追踪当前提示和模型组合的已见偏差，尤其是缺失字段和结构化参数。失败解释类别使用固定运行证据验证事实、推断和脱敏，尚无真实模型评分。模型提示的自由文本、回复的自由文本和真实用户数据均未归档。

## 复现命令

在包含本项评估文件的原型根目录运行，使用新证据目录。固定源复跑可从上述基线提取 `src`、`config`、`tests/method_dev/fixtures`、`pyproject.toml` 后叠加 `tests/agent/evals`。

```bash
set -euo pipefail
agent_eval_results=$(mktemp -d /dev/shm/geopilot-p15-08-results.XXXXXX)
agent_eval_base=$(mktemp -d /dev/shm/geopilot-p15-08-evals.XXXXXX)
export PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONDONTWRITEBYTECODE=1 PYTHONPATH="$PWD/src:$PWD"
GEOPILOT_AGENT_EVAL_REPORT="$agent_eval_results/p15-08-mock.json" \
  .venv/bin/python -m pytest tests/agent/evals -q -p no:cacheprovider --basetemp="$agent_eval_base" \
  --junitxml="$agent_eval_results/p15-08-mock-junit.xml" \
  2>&1 | tee "$agent_eval_results/p15-08-mock.log"

.venv/bin/python tests/agent/evals/replay_ollama.py --enable-local-model \
  --ollama-binary /path/to/ollama --models /path/to/local-model-store \
  --report "$agent_eval_results/p15-08-ollama.json" \
  2>&1 | tee "$agent_eval_results/p15-08-ollama.log"
```
