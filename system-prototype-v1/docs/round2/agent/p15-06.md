# P15-06 生成式 GIS 候选的本机隔离试跑

Agent C 执行，主控复核，状态 ACCEPTED。试点将候选 Python 函数用于一个固定单波段 GeoTIFF 的高程阈值计数。候选接受有效像元列表和阈值，返回有效像元数及大于等于阈值的像元数。通过时报告进入 `REVIEW_REQUIRED`，供维护者复核候选摘要和样例结果。 [批准契约](p15-06-rfc.md)

## 使用

在原型根目录运行，使用已安装的项目 GIS 依赖和本机固定镜像。`--describe` 输出候选签名和语法约束，`--generate` 输出对应的确定性本地候选源码。两者均可在不启动容器时执行。将候选保存到新建的临时目录，再用 `--candidate` 运行审核。该入口也接受维护者或模型在外部生成的候选。

```bash
sandbox_review=$(mktemp -d)
PYTHONPATH=src .venv/bin/python -m geopilot.llm.generated_tool_sandbox --describe
PYTHONPATH=src .venv/bin/python -m geopilot.llm.generated_tool_sandbox \
  --generate > "$sandbox_review/candidate.py"
PYTHONPATH=src .venv/bin/python -m geopilot.llm.generated_tool_sandbox \
  --candidate "$sandbox_review/candidate.py"
```

候选为 UTF-8 普通文件，长度上限 4096 字节，AST 上限 256 个节点。函数签名固定为 `count_threshold(values, threshold)`，返回键固定为 `valid_count` 和 `selected_count`。可使用局部变量、数值和布尔字面量、算术、比较、分支、循环、列表及结果字典。导入、调用、属性、下标、自由变量和参数写入会在启动进程前拒绝。主机与可信包装器各执行一次语法检查。

```python
def count_threshold(values, threshold):
    valid = 0
    selected = 0
    for value in values:
        valid += 1
        if value >= threshold:
            selected += 1
    return {"valid_count": valid, "selected_count": selected}
```

CLI 的 v1 JSON 报告包含源码和包装器摘要、样例清单与栅格摘要、参考和实际计数、容器策略、执行状态、资源上限与清理结论。调用者可按需将报告保存到独立审阅目录。退出 0 对应 `REVIEW_REQUIRED`，退出 1 对应候选、参考、隔离或结果未通过，退出 2 对应输入文件或命令用法无效。Python 调用为 `review_candidate(source, cancel_requested=...)`，可通过回调取消运行。正式工具收录继续由人工审批与既有方法发布流程处理。

## 独立 GeoTIFF 参考

复用 P14-04 的 `dem-terrain` 样例。宿主校验固定原始清单和 DEM 的 SHA-256、单波段 7×7 范围、原始仿射网格、NoData、单位和比例。使用现有面积策略确认 EPSG:6933 等积米制网格，并由 10 m × 10 m 仿射像元得到 100 m² 面积。宿主剔除两个 NoData 后，仅将 47 个有效像元的数字列表和固定阈值序列交给容器。 [原始样例清单](../../../tests/method_dev/fixtures/dem-terrain/manifest.json)

手算依据为每行从 100 至 160 以 10 m 递增，左上和右下为 NoData。大于等于 130 的四列各七个像元，扣除右下角后为 27，其中恰为 130 的有效像元有七个。候选只返回计数，面积由可信宿主按已验证的单像元面积换算。

| 阈值 | 有效像元 | 达标像元 | 达标面积 |
|---|---:|---:|---:|
| 100 | 47 | 47 | 4700 m² |
| 130 | 47 | 27 | 2700 m² |
| 161 | 47 | 0 | 0 m² |

## 威胁模型与资源边界

- 候选源码视为不可信。主机仅解析、静态检查和暂存源码，真正执行发生在已检查策略的容器。容器入口清空镜像继承环境，以隔离 Python 启动可信包装器，候选函数的全局内置表为空。报告只记录结构化结论和摘要。
- 本机 Docker 使用固定 Unix 套接字和私有空客户端配置。容器使用内容固定的本地镜像 `sha256:c618d0d9d91d0cf473d61e5fc284aa335e87caabd51381b73cd61b2d0f93cb87`，拉取策略为 `never`。运行时检查网络禁用、非特权用户、无 capabilities、禁止提权、seccomp、只读根目录及唯一只读挂载。挂载包含候选源码、可信包装器和派生数字 JSON。原始 GeoTIFF、项目目录、数据库、Docker 套接字、宿主凭据与模型上下文均在挂载外。
- 资源上限为 64 MiB 内存及同值内存加交换空间、0.5 CPU、16 个进程、64 个打开描述符、4 秒 CPU 时间、4 秒附加运行墙钟和 1024 字节结果。Docker 控制命令各限时 5 秒。包装器只输出固定形状的整数 JSON，宿主重新验证格式和范围。
- 容器使用独立身份。正常、超时、取消和运行失败均按本次身份清理并查询不存在。遇到运行时缺失或清理无法验证时，报告保留可复核的错误，审批门禁关闭。墙钟上限覆盖启动附加过程，检查和清理各有独立时限。
- 可信计算基包含固定镜像、宿主验证代码、本机 Docker 守护进程和内核。固定样例是人工审阅的证据，候选未来的适用范围、正确性和发布资格仍需单独评估。

## 实测结果

固定源码基线为 `d580bf25abefa6775fdb1c427c2c23fee29409a7`，叠加本项两个模块及专项测试。宿主 Python 3.13.13、pytest 8.3.4、Rasterio 1.4.3、GDAL 3.9.3，Docker Engine 28.1.1，容器内 Python 3.12.3。原始工作目录为 `/dev/shm/geopilot-p15-06-tests.XntJ12`。UTC 06:31:30 至 06:31:41 功能窗口内，开始与结束的 I/O PSI `some/full avg10` 均为 0.00%。

- 首次轻量专项退出 0，19 通过，6 个容器测试未选中，0.43 秒。验证文件和语法边界、路径与凭据形态的静态拒绝、固定样例篡改、运行时不可用及无法确认清理时的拒绝。静态拒绝用例均在零子进程启动时结束。 [日志](p15-06-static.log) · [JUnit](p15-06-static-junit.xml)
- 完整专项退出 0，25 通过、0 失败、0 跳过，10.37 秒。六个真实容器用例结束后，分别用容器 ID 和名字再次检查不存在。 [日志](p15-06-pytest.log) · [JUnit](p15-06-junit.xml)
- 正例完整执行 `--describe`、`--generate`、`--candidate`，三条命令均退出 0。确定性模板在隔离目录落为源码并运行，真实 GeoTIFF 的三个阈值与手算一致，报告为 `REVIEW_REQUIRED`。模型供应商生成未在本试点实测。原样例、正式工具目录和模拟正式项目数据库及成果的文件摘要与修改时间均保持原样。模拟宿主凭据标记与源路径未进入报告。 [生成记录](p15-06-generation.json) · [审阅报告](p15-06-review.json)
- 错用严格大于的函数在容器内正常退出，宿主因漏计等于阈值的像元拒绝，返回 `REFERENCE_MISMATCH`。返回布尔值的函数由包装器以退出 2 拒绝，宿主返回 `CANDIDATE_OUTPUT_INVALID`。 [参考失配](p15-06-reference-mismatch.json) · [结果类型不符](p15-06-invalid-result.json)
- 纯数字列表分配压力触发真实 cgroup OOM，Docker 标记 `OOMKilled=true`，退出 137，宿主返回 `SANDBOX_MEMORY_LIMIT`。纯计算循环的墙钟超时发生于 4.022 秒，主动取消发生于 0.823 秒。两次控制客户端退出时容器仍处于运行状态，随后按本次身份强制移除并验证不存在。 [内存限制](p15-06-memory.json) · [超时](p15-06-timeout.json) · [主动取消](p15-06-cancel.json)

实测容器环境仅保留预期变量，UID/GID 为 65534，有效 capabilities 为零，开启 seccomp 和禁止提权，根目录与暂存目录实际为只读。检查到网络为 `none`、IPC 为 `none`、cgroup 命名空间为 `private`，唯一挂载和资源设置符合契约。网络形态拒绝测试止于 AST 检查。 [实际策略与运行环境](p15-06-review.json)
