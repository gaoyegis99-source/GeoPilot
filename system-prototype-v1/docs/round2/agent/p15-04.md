## 实现与边界

- `GET /api/plans/{plan_id}/alternatives?version=N` 以保存的精确方案版本为基线。候选来自启用的方法及其声明的工具分支。同 ID 可比较其他版本。跨方法比较要求预期成果角色与类型完全匹配。
- 保留角色和类型匹配的精确资产引用，重新核验本机资产、候选工具、参数和检查规则。兼容的筛选范围及成果条件随草稿保留。不同方法只继承规格相同的参数。数据派生参数按候选方法重新计算。
- 工作台按需比较输入、参数及约束、工具、成果和待补项。用户点选「采用并生成草稿」后，现有任务计划接口保存新版本。随后通过原确认入口审查，执行仍需用户发起。
