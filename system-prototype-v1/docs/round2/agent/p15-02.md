主控执行并签收 ACCEPTED。验证使用 `90c79597be956cc2e9fb52e78dc9ca70be67f4f7` 加本项文件。环境为 Ubuntu 20.04.6、Linux x86_64、Python 3.13.13、pytest 8.3.4、Node 22.23.1、npm 10.9.8、Vitest 5.0.5 和 TypeScript 5.9.3。

## 接口与行为

- `GET /api/plans/{plan_id}/clarification?version=N` 返回精确草稿的待答字段和本地候选。已确认版本返回已确认状态。
- `POST /api/plans/{plan_id}/clarification` 接受 `plan_version`、`field` 和 `value`。每次合并一个目标、输入或关键选项，沿用现有上下文、方法验证和草稿版本服务。先前的目标诊断和仍适用的无效参数诊断随新草稿保留。
- 版本竞争返回 409。已确认版本及非当前方案族的历史草稿仍可查看。资产替换时重新核验精确引用及来源指纹。待运行草稿需通过原确认入口，确认后的运行继续引用其原版本。
- 工作台逐项保存回答，回写地址栏中的精确版本。刷新时从后端恢复同一草稿及其任务上下文。待答项继续阻断确认。前端复用现有方法字段控件。
