## 交付

`method_cli.py` 提供 `inspect`、`validate` 和 `report`，固定 JSON 结果版本、字段、退出码和路径基准。V1 的严格 YAML 加载器、`RegistrationCandidate` 与 `validate_manual_registration` 提供解析和完整试验证据核验。 `inspect` 明示结构核验范围。 `report` 每次重新核验并输出候选与证据，处置状态为 `manual_review_required`。下一阶段的模板、lint、样例包、试运行和人工发布沿用命令契约。 [CLI 命令契约](../../method-authoring/cli.md) · [V1 手工收录指南](../../method-authoring/README.md)
