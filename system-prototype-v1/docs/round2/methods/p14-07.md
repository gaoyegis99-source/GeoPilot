## 审核与发布

在原型根目录运行。准备候选 YAML 和与其精确方法 ID、版本匹配的样例包。安装项目 GIS 依赖和 `requirements-test.txt`。

```bash
release_evidence=$(mktemp -d)
.venv/bin/python scripts/methods/method_cli.py prepare-release \
  --catalog-dir /path/to/config/methods \
  --method /path/to/candidate.yaml --package /path/to/manifest.json \
  --work-dir "$release_evidence/review"
```

`prepare-release` 在新目录逐一运行样例包正例和声明的全部失败用例。审核 `review.json` 及其引用的原始 `cases/<case>/report.json`。正例必须执行成功、通过 V1 检查并匹配独立参考。失败用例必须在指定阶段返回约定错误且没有运行。CLI 给出 `approval_sha256`，它绑定审核摘要和每份报告的路径及原始字节指纹。

```bash
.venv/bin/python scripts/methods/method_cli.py publish \
  --catalog-dir /path/to/config/methods \
  --method /path/to/candidate.yaml --package /path/to/manifest.json \
  --work-dir "$release_evidence/replay" --review "$release_evidence/review/review.json" \
  --approve '<review SHA-256>' --approver '<maintainer>' --reason '<approval reason>'
```

QGIS 用例可在两次命令中给出相同的 `--qgis-process`。两次命令的 `--timeout` 分别为每个用例设置时限，默认 120 秒。发布核对候选和样例清单字节、目标目录的 YAML、项目 Python 源码、QGIS 入口指纹及实际环境。仓库提供的 QGIS 包装器同时绑定其构建文件和脚本内的镜像摘要。自备 QGIS 入口使用本机可信部署，报告记录入口文件和实测版本。复验采用新目录并再次逐例运行。运行 ID、路径、耗时和可变的输出字节指纹保留在原始报告中，稳定摘要比较逐例判定、独立结果指标和环境。

完整审核及复验证据均在各自目录保留。发布台账记录两份 `review.json` 的路径、逐例报告的路径和指纹、批准摘要、批准者、原因、时间以及与审批一致的候选 YAML 字节。发布使用目录内排他锁，校验整条台账后原子替换文件。重复精确版本拒绝写入。锁冲突返回 `CATALOG_BUSY`，可在新的复验目录重试。

## 禁用和回滚

用 `disable` 停用一个精确发布版本。当首发方法没有可回滚前驱时，用该命令撤回。使用 `rollback` 时，目标必须为同 ID 更早的精确版本。台账版本的目标摘要取其原发布事件的 `approval.sha256`。内置版本的目标摘要由其规范化 `MethodDefinition` 生成。

```bash
.venv/bin/python scripts/methods/method_cli.py disable \
  --catalog-dir /path/to/config/methods --method example-method@1 \
  --approver '<maintainer>' --reason '<withdrawal reason>'

.venv/bin/python scripts/methods/method_cli.py rollback \
  --catalog-dir /path/to/config/methods --from example-method@2 --to example-method@1 \
  --approve '<target SHA-256>' --approver '<maintainer>' --reason '<rollback reason>'
```

内置目标摘要计算示例。

```bash
PYTHONPATH=src .venv/bin/python - <<'PY'
from geopilot.methods.loader import load_method_catalog
from geopilot.methods.release_ledger import fingerprint

catalog = load_method_catalog("/path/to/config/methods", include_releases=False)
if catalog.issues:
    raise ValueError(catalog.issues)
method = catalog.get("example-method", 1)
print(fingerprint(method.model_dump(mode="json")))
PY
```

禁用和回滚追加事件。所有版本仍可按精确历史引用读取，已确认方案的执行和既有成果可继续使用原版本。重新启动后，目录、模型候选、新草稿和待确认草稿使用更新的启用集合。内置版本默认启用。所有命令沿用 CLI v1 JSON 信封。退出 0 为成功，退出 1 表示验证或台账操作失败，退出 2 表示用法不合要求。

```bash

release_git_root=$(git rev-parse --show-toplevel)
release_baseline=861a0767c62b5da02a38aeae8c1156c30ed81a0c
release_source=$(mktemp -d /tmp/geopilot-p14-07-source.XXXXXX)
git -C "$release_git_root" archive "$release_baseline" \
  system-prototype-v1/config system-prototype-v1/src system-prototype-v1/scripts \
  system-prototype-v1/tests system-prototype-v1/pyproject.toml \

cp --parents -- scripts/methods/method_cli.py scripts/methods/release.py scripts/methods/trial.py \
  src/geopilot/methods/loader.py src/geopilot/methods/release_ledger.py \
  src/geopilot/api/catalog_routes.py src/geopilot/api/model_routes.py src/geopilot/api/task_routes.py \

  printf 'baseline %s\nsource %s\nrelease test evidence root %s\n' "$release_baseline" "$PWD" "$release_base"
```
