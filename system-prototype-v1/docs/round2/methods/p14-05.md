## 复现命令

在原型根目录执行。实际专项验证使用新的 pytest 目录，并指定本地 QGIS Processing。Linux 上的超时验证检查两个前台进程的 `/proc` 状态。

```bash
set -euo pipefail
trial_base=$(mktemp -d /tmp/geopilot-p14-05-tests.XXXXXX)
export PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONDONTWRITEBYTECODE=1
export GEOPILOT_QGIS_PROCESS="$PWD/.environments/qgis-deb/qgis_process"
{
  printf 'trial test evidence root %s\n' "$trial_base"
  git rev-parse HEAD
  .venv/bin/python -V
  .venv/bin/python -m pytest tests/method_dev/test_trial_run.py -q \
    -p no:cacheprovider --basetemp="$trial_base" \
    --junitxml=docs/round2/methods/p14-05-junit.xml
} 2>&1 | tee docs/round2/methods/p14-05-pytest.log
```

## 接口与回滚

`trial` 保持 CLI 的 JSON 信封版本 1。每次使用独立工作目录及 SQLite。引用的工具实现、检查、正式 V1 API 和项目配置均来自既有项目。试跑输入来自新目录中校验过的只读副本。正式数据库和工作区不在试跑读写路径内。若试跑超时，保留工作目录以供诊断。隔离覆盖受信任的本地前台进程组，命令返回会等待同步 V1 操作及取消回收。单独的审批发布流程可查验 `positive_match`、精确方法及指纹、V1 检查与独立比较结果。

回滚时移除新增的 `trial.py`、`test_trial_run.py` 及相应说明、证据，撤销 `method_cli.py` 中的 `trial` 接入。已生成的工作目录可独立留存或清理。
