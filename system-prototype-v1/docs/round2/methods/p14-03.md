## 复跑命令

在原型根目录执行。第二条命令预期退出 1。pytest 记录同时保留 JUnit 与 stdout/stderr。

```bash
export PYTHONDONTWRITEBYTECODE=1
GEOPILOT_QGIS_PROCESS=/nonexistent/qgis-process .venv/bin/python scripts/methods/method_cli.py lint \
  > docs/round2/methods/p14-03-catalog.json
GEOPILOT_QGIS_PROCESS=/nonexistent/qgis-process .venv/bin/python scripts/methods/method_cli.py lint \
  --method config/methods/road-buffer-statistics.v1.yaml \
  > docs/round2/methods/p14-03-single-example-rejected.json

set -o pipefail
export PYTEST_DISABLE_PLUGIN_AUTOLOAD=1
.venv/bin/python -m pytest -q -p no:cacheprovider tests/method_dev/test_lint.py \
  --junitxml=docs/round2/methods/p14-03-lint-junit.xml \
  2>&1 | tee docs/round2/methods/p14-03-lint.log
.venv/bin/python -m pytest -q -p no:cacheprovider \
  tests/method_dev/test_method_cli.py tests/method_dev/test_template_generation.py \
  --junitxml=docs/round2/methods/p14-03-cli-regression-junit.xml \
  2>&1 | tee docs/round2/methods/p14-03-cli-regression.log
```
