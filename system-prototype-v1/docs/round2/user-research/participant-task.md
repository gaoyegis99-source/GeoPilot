# 受试任务单

你需要交付一份分区 CSV，说明样例分析范围内，各区有多少目标点与道路的 500 米缓冲范围相交。请在提供的 GeoPilot 工作台上完成。

- 工作台网址（主持填写）
- 样例 GeoPackage 路径（主持填写，复制此路径登记数据）

1. 将样例中的分析范围 `analysis_extent`、道路 `roads`、目标点 `targets` 和统计分区 `zones` 登记到工作台。
2. 选择「道路缓冲统计」版本 3，填写任务目标，为四个角色选择正确的样例资产，生成方案草稿。
3. 核对并确认方案。使用 500 米、局部投影 `EPSG:32650`、相交、质心归属、边界并列时未归属、计数和裁回分析范围。
4. 启动运行，等待执行完成并说明你看到的执行状态。
5. 查看本次结果的检查，打开一条规则明细，并说明你看到的检查结论。
6. 下载本次运行的分区统计原始 CSV。打开文件，说明西区、东区、未归属及总计各有多少目标点。

可以按平时习惯探索界面。如需帮助或希望停止，请告诉主持。
