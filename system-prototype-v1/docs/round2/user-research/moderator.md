# P16-03 工作台可用性观察主持手册

面向平时使用桌面 GIS、熟悉图层与空间关系、此前未使用 GeoPilot 的人员。建议至少 5 人，兼顾经常和偶尔使用 GIS 的人员。每人独立完成同一任务，安排约 30 分钟。开场说明观察针对工具本身，参与者可随时停止。征得同意后仅记录匿名编号、任务过程和结果。开发者的联调与演示记录单独存放。

## 开始前

1. 固定本批次 GeoPilot 提交，记录浏览器端的 OS、浏览器版本以及后端 QGIS 版本。使用已核验的工作台和后端。参与者通过浏览器操作，由主持人准备后端及样本。
2. 每次会话用一个新的 SQLite 路径、工作目录和下载目录。浏览器用独立会话，清空上次选择。验证工作台打开且资产和历史运行为空，方法目录中版本 3 可用。
3. 将原型下的 `tests/fixtures/vector/road-buffer.gpkg` 绝对路径填进受试任务单。保持样例原件只读。开始前确认浏览器可下载，下载目录可读取 CSV。为主持准备计时器和观察记录。
4. 将任务单交给参与者，读出目标即可。请其说出选择原因及对界面反馈的理解。主持手册和答案只供观察员使用。 [启动说明](../../../README.md#启动工作台) · [受试任务单](participant-task.md)

## 任务边界与答案

| 记录键 | 开始与结束 | 完成条件 |
|---|---|---|
| `register_assets` | 从交付目标并交还界面控制开始，到四个资产登记完成或放弃 | 同一 GeoPackage 中 `analysis_extent`、`roads`、`targets`、`zones` 各登记一次，保留原 CRS。 |
| `select_method` | 从首次进入方法选择到草稿可用或放弃 | 选择「道路缓冲统计」v3，四个角色映射正确，草稿保存规定参数。 |
| `confirm_plan` | 从草稿可用到确认成功或放弃 | 参与者核对输入版本、500 米与距离口径，并确认该草稿。 |
| `run_plan` | 从确认完成到识别本次运行的终态或放弃，计入处理等待 | 从确认方案启动运行，并识别执行成功 `SUCCEEDED`。 |
| `inspect_checks` | 从参与者识别执行终态到查看检查明细并报告结论或放弃 | 报告检查通过 `PASSED`，打开至少一条规则明细，并指出执行与检查的各自结果。 |
| `download_result` | 从找到成果区到保存原 CSV 并读出分区计数或放弃 | 下载本次 `zone_statistics` 正式成果，`zone_id/count` 为 `zone-west/3`、`zone-east/2`、空值 `/1`，合计 6。 |

正确参数为局部投影 `EPSG:32650`、500 米、相交、质心归属、边界并列时未归属、计数、裁回分析范围。计划包含七步，局部投影的统计参考来自 V1 固定样本。主持从参与者实际下载的 CSV 核对数值。 [方法配置](../../../config/methods/road-buffer-statistics.v3.yaml) · [独立参考](../../../tests/fixtures/vector/expected.json) · [固定用例复验](../audit/p12-07.md)

## 观察与干预

- 一位参与者记一个匿名编号，从 U001 开始。只在登记任务已开始后建立会话。计时使用秒，尝试过但未完成也记录耗时。若参与者停止，尚未尝试的后续任务全部标 `not_attempted`。
- 有明确求助时每次计 1。主持重复目标或请对方描述当前界面可先作为中立追问。实际提供方向或操作信息时标记 `assisted: true`，即使帮助由主持主动提供。由参与者完成操作时仍按完成条件记录。主持代替参与者完成某一步时该任务标 `incomplete`，若无法继续则结束会话。
- 将阻断、错误选择或错误理解作为事件逐条记录，重复触发也计事件。界面显示稳定错误码时可使用其代码，其他情况可用 `WRONG_LAYER`、`WRONG_METHOD_VERSION`、`CONFIRMATION_BLOCKED`、`MISREAD_STATUS`、`WRONG_DOWNLOAD` 等类别。每条标明自行恢复、协助恢复或未恢复。把偶发环境阻断和界面问题写进观察员匿名简记，供结果解释。
- 任务完成后可问「你在哪里确认本次运行是否成功？」与「你怎么判断下载的文件属于这一次运行？」。只记录与界面和任务有关的匿名观察。浏览器下载、匿名备注与原始记录保存在约定研究目录，汇总报告仅发布计数和耗时。 [记录格式](observations.md)
