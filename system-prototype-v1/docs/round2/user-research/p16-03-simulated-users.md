## 建议优先处理

1. **修正恢复指引。** 测量 CRS 不适用时将「定位」指向距离坐标参考系。取消终态提供清晰的「按原方案重新运行」入口，保留查看日志。
2. **区分执行与检查。** 首次使用角色观察到「运行成功」「取消运行」「规则检查中」短暂同时出现。三个角色都记录了成功后仍显示「当前步骤 aggregate_by_zone · 0 秒」。检查阶段明确取消对象，终态显示最后完成步骤。
3. **减少重复操作和复核成本。** 支持连续登记同一 GeoPackage 的图层，修改表单后让更新草稿的动作更明确。方案预览显示「500 米」，成果卡和下载文件名附带可辨识的运行编号或时间，便于核对多次运行。

首次使用角色的浏览器控制脚本出现一次隐藏元素重复匹配，改用可见规则后完成操作。三条角色记录均无页面异常。此次结论适用于固定样本及所用浏览器布局。
