## 退出条件证据

- 真实 GeoTIFF 与 GeoPackage 在登记进程退出后，可由另一个进程仅用数据库和 `asset_id`、`asset_version` 重开。范围、CRS、字段或波段摘要及原始指纹一致。[跨进程证据](P1-09.md)
- 内容变化沿用资产 ID 追加版本，原方案中的旧引用及历史行不变。旧引用在字节不匹配时报告 `INPUT_CHANGED`，恢复原字节后可重开。仅触摸 mtime 复用当前版本。[版本证据](P1-08.md)
- 本机文件、读取失败、缺图层、格式伪装和缺 CRS 分别有可定位结果。测试复核原始文件指纹保持，读取过程中变化不会创建可用记录。[登记证据](P1-07.md)
- SQLite 初始化失败时回滚 schema 和版本，保留原有记录。运行目录碰撞、链接穿越和部分创建失败有错误证据，已存在的文件保留。[SQLite](P1-01.md) · [运行目录](P1-10.md)
