# P8-09 NDVI 变化分类与等积统计

2026-11-12 主控签收，主控联合 240 项通过。执行角色 Agent-F。[主控 JUnit](../../artifacts/test-results/p8-09-root-junit.xml)`classify_ndvi_change(source, destination, *, threshold, area_crs)` 接收 P8-08 的同格 Float64 `ndvi_change`，单位 `1`、NaN NoData、恒等 GDAL 缩放。阈值为 `0` 至 `2` 的有限数。分类按第二期减第一期的差值执行。[实现](../../src/geopilot/remote_sensing/classification.py)

| 编码 | 类别 | 区间 |
|---|---|---|
| 1 | `decrease` 减少 | `< −threshold` |
| 2 | `stable` 稳定 | `−threshold ≤ 差值 ≤ threshold` |
| 3 | `increase` 增加 | `> threshold` |
| 255 | NoData | 输入 NaN、无效掩膜或非有限像元 |

返回 `ChangeClassificationResult(metadata, statistics)`。分类成果保留原 CRS、仿射和宽高，单带 `threshold_class` 采用 UInt8，单位 `class`。面积统计沿用 P7 的等积投影适用性检查与原像元足迹，明确记录源和目标 CRS、平方米单位、面积策略、有效与 NoData 数量、阈值和变化方向。三个类别均有 `class_id`、`class_name`、`pixel_count` 和 `area_m2`，空类的计数和面积为零。面积成功后才将分类文件发布到目的路径，已有目标或伴随文件会触发 `FileExistsError`。[分类](../../src/geopilot/gis/raster/threshold.py) · [面积](../../src/geopilot/gis/raster/area_stats.py)

先行专项退出 `2`，缺少 `geopilot.remote_sensing.classification`。实现后专项退出 `0`，`16 passed in 0.61s`。联合退出 `0`，`280 passed in 7.18s`。[先行 JUnit](../../artifacts/test-results/p8-09-red-junit.xml) · [专项 JUnit](../../artifacts/test-results/p8-09-junit.xml) · [联合 JUnit](../../artifacts/test-results/p8-09-joint-junit.xml)

- 在 EPSG:6933 的剪切网格重开分类 GeoTIFF。阈值 `0.25` 的两个端点均为稳定，紧邻端点的可表示浮点值各自落入变化类。NaN 与 GDAL 掩膜的两个像元均为 255。像元面积 `|20 × (−10) − 3 × 4| = 212 m²`，减少、稳定、增加为 `3/3/2` 格和 `636/636/424 m²`，合计 `1696 m²`。
- 阈值 `0` 的有符号零均为稳定。阈值 `2` 包含差值 `−2` 和 `2`，减少与增加各保留零值统计。全 NoData 样本保留网格和三行零统计。
- 真实调用 P8-07 与 P8-08 生成 EPSG:32632 的 30 米差值样本。重开分类为 `[[1, 2, 3, 255]]`。每类一格，面积约 `900.7204 m²`。以 WGS84 椭球和 256 段每边的独立像元边界核对，每类绝对差在 `1e-5 m²` 以内。分类网格仍为原 UTM 仿射。
- 错误阈值、源带名称或缩放、非等积面积目标、已有目标及伴随文件均触发相应错误。EPSG:3857 面积拒绝后正式文件和分类暂存均不存在，输入指纹保持一致。[专项测试](../../tests/remote_sensing/test_change_classification.py)

面积按参与统计的整格足迹计算，分析区内的像元归属由上游对齐负责。统计 JSON 随正式方法在 P8-10 发布。本任务包含真实 GeoTIFF 和上游差值串接的分类证据。
