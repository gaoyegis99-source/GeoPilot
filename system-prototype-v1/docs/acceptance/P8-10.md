# P8-10 两期 NDVI 正式方法

2026-11-12 主控签收，A 负责原生打包，B 负责八工具，F 负责固定用例与独立浏览器，主控装配方法、接口和检查。

`remote-sensing-index-change@1` 以三项已登记资产进入同一工作台的草稿、确认和运行入口。用户确认重采样、变化阈值与面积 CRS。服务从两个真实产品重开原 XML、确认唯一配置、校验波段及定标字段，并把完整配置快照保存在方案版本。八个固定 Python 步骤依次读取产品、查找配置、映射波段、定标、生成质量掩膜、计算 NDVI、对齐和计算变化。[方法](../../config/methods/remote-sensing-index-change.v1.yaml) · [方案前置](../../src/geopilot/application/remote_sensing_plan.py) · [八步执行](../../src/geopilot/gis/tools/remote_sensing_workflow.py) · [成果检查](../../src/geopilot/application/remote_sensing_checks.py)

正式成果包含配置、定标、两期质量掩膜和原网格 NDVI、对齐记录、连续差值、三类变化和面积统计。定标、掩膜及原 NDVI 的来源标签保留期别、产品、确切配置和运行内源指纹。原始 TIFF 与工作台的显示预览使用既有 P7 成果和像元接口。

## 原生产品接入

本机打包器读取原 MTL 或 SAFE XML 与逐带文件。它保留原 DN、原 XML、源文件与伴随掩膜指纹。Sentinel-2 的 20 米 SCL 在打包时以最近邻对齐至 10 米光谱网格，随后 GeoTIFF 可走既有 P1 登记。[原生打包验收](P8-10-product-pack.md) · [打包器](../../src/geopilot/remote_sensing/product_pack.py)

主控用相同合成 DN 重构实际 Landsat TIFF 和 Sentinel-2 JP2。首个重构样本漏写源伴随掩膜，流程正确报告原 NDVI 范围警告。保留正确原生伴随掩膜的样本打包后，所有必需 DN 与共同掩膜都逐像元匹配参考源。由这些原生文件生成的新资产随后在浏览器实际完成八步，检查通过，面积 3602.8817283728354 m²。[原始诊断报告](../../artifacts/smoke/p8-native-workbench/missing-native-mask-warning.json) · [原生打包后的正式浏览器运行](../../artifacts/smoke/p8-native-workbench-verified/browser.json)
