# P1-10 运行工作目录

2026-11-11，建议状态 `REVIEW`。依赖 P0-01 与 P1-01 已验收。实现对应 V2.0 §8.2 和 P1-10 冻结契约。

`create_run_workspace(root, task_id, run_id)` 返回 `RunWorkspace`，提供运行目录 `path`、确认请求位置 `request_path` 和取消标记位置 `cancel_path`。`create_step(step_key)` 返回独立步骤目录。目录由该模块创建，文件由调用服务在相应阶段写入。

```text
{root}/tasks/{task_id}/runs/{run_id}/
  request.json
  cancel.flag
  inputs/
  steps/{step_key}/
    request.json
    result.json
    process.log
  intermediate/
  outputs/
  previews/
  checks/{report_id}.json
```

根路径规范化后逐级打开子目录，逐层拒绝符号链接。ID 只作为单个目录名，拒绝空白、控制字符、路径分隔符、盘符和路径跳转。运行目录及步骤目录由原子 `mkdir` 分配，重复路径报 `FileExistsError`。操作失败保留系统错误码和失败路径。初始化中途失败时用 `rmdir` 清理本次创建的空子目录与运行目录，共享父目录继续供其他运行使用。清理受阻时保留已有内容和原始异常，异常附注记录未清理路径。

验证在 Ubuntu、Python 3.13.13、pytest 8.3.4 执行，临时目录与其他项目隔离。

```bash
p1_workspace_tmp=$(mktemp -d /tmp/geopilot-p1-10.XXXXXX)
PYTEST_DEBUG_TEMPROOT="$p1_workspace_tmp" PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 \
  python -m pytest tests/workspace -q --junitxml=artifacts/test-results/p1-10-junit.xml
```
