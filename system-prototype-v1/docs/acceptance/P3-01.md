## 公共接口

`geopilot.methods.models` 提供 `MethodRef`、`MethodDefinition` 和 `MethodStep`。`MethodDefinition.ref` 返回方法的精确版本。方法和工具版本均须为正整数，`locked_order` 须为布尔值。字段和绑定拒绝额外键，角色和数据类型用非空名称声明。输入角色、选项、步骤、前提、成果和规则保留声明顺序。省略 `preconditions` 时使用空序列。

带类型的数值等选项复用 `ParameterSpec`，枚举列表规范为 `ParameterSpec(type="enum", values=...)`。`ReferenceOption` 可声明 `required_for` 条件。附录中的 `user_defined` 和 `user_selected` 原样保留。

`MethodStep` 支持精确 `ToolRef`、`AssetRoleBinding` 和 `StepOutputBinding` 输入、`OptionBinding` 和 `LiteralBinding` 参数、命名输出类型。未指定工具的示例步骤可只声明 `key`。`ExpectedArtifactBinding` 指定成果角色、步骤、输出和类型，也可用附录中的成果名称简写。

Schema 使用 Pydantic 2.13.5 的 `model_json_schema()` 生成，两份文件均通过 Draft 2020-12 `check_schema`。[方法定义及内嵌步骤 schema](../../artifacts/schemas/method-definition.schema.json) · [方法引用 schema](../../artifacts/schemas/method-ref.schema.json)

从原型根目录重建并验证源文档示例：

```bash
PYTHONPATH=src python - <<'PY'
import json
from pathlib import Path

import yaml
from jsonschema import Draft202012Validator

from geopilot.methods.models import MethodDefinition, MethodRef

validators = {}
for model, name in ((MethodDefinition, "method-definition"), (MethodRef, "method-ref")):
    schema = model.model_json_schema()
    Draft202012Validator.check_schema(schema)
    Path(f"artifacts/schemas/{name}.schema.json").write_text(
        json.dumps(schema, indent=2, ensure_ascii=False) + "\n", encoding="utf-8"
    )
    validators[model] = Draft202012Validator(schema)

source = Path("../docs/source/GeoPilot_产品需求规格与系统详细设计报告_V2.0.md")
document = source.read_text(encoding="utf-8")

def read_example(heading):
    section = document.split(heading, 1)[1]
    return yaml.safe_load(section.split("```yaml\n", 1)[1].split("```", 1)[0])

examples = [
    {**read_example("## 8.5 MethodDefinition"), **read_example("## A.1 道路缓冲统计")},
    read_example("## A.2 DEM 地形分析"),
    read_example("## A.3 遥感变化"),
    read_example("## A.4 土地利用变化"),
]
for example in examples:
    validators[MethodDefinition].validate(example)
    method = MethodDefinition.model_validate(example)
    assert method.ref == MethodRef(id=example["id"], version=example["version"])
    validators[MethodRef].validate(method.ref.model_dump(mode="json"))
    assert list(method.inputs) == list(example["inputs"])
    assert list(method.critical_options) == list(example["critical_options"])
    assert [step.key for step in method.steps] == [step["key"] for step in example["steps"]]
    assert list(method.preconditions) == example.get("preconditions", [])
    assert list(method.expected_artifacts) == example["expected_artifacts"]
    assert list(method.check_rules) == example["check_rules"]
    validators[MethodDefinition].validate(method.model_dump(mode="json"))
    assert MethodDefinition.model_validate_json(method.model_dump_json()) == method
    print(f"{method.id} v{method.version}  {len(method.steps)} steps  PASS")
PY
```
