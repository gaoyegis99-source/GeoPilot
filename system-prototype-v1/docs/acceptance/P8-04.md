## 核对结果

- Landsat 使用 `DN × scale + offset`。真实 GeoTIFF 的红光 10000 与近红外 20000 分别重开为 `0.075` 与 `0.35`，手算红光 18639 为 `0.3125725`。标准系数 `0.0000275` 与 `−0.2` 来自本次输入 XML。另改写合成 XML 的两波段系数和偏移，257 × 259 像元跨分块重开为红光 `0.4` 与近红外 `0.23`。元数据中的 Level-1 同名字段保留作干扰项。[USGS Landsat Collection 2 缩放说明](https://www.usgs.gov/faqs/how-do-i-use-a-scale-factor-landsat-level-2-science-products)
- Sentinel-2 按原生波段 ID 3 和 7 读取偏移，以 `(DN + BOA_ADD_OFFSET) / BOA_QUANTIFICATION_VALUE` 计算。DN 800 与 1200 重开为 `−0.02` 与 `0.02`，相加在 Float64 中等于零。DN 1000 的反射率为有效 `0.0`，原 DN `0` 为 NaN。改写合成 XML 的量化值和两个不同偏移后，手算与实际红光 `0.0883`、近红外 `0.23275` 一致。[Copernicus Sentinel-2 产品说明](https://sentiwiki.copernicus.eu/web/s2-products)
- 结果保留原 CRS、仿射、宽高和网格。原始 GDAL 有效掩膜与每波段的配置填充值共同确定各波段有效像元。云位、饱和位和 SCL 在此步骤仍保持为源产品信息。复验源文件指纹一致。
- 缺失字段、非有限或非正系数、与真实波段不符的偏移 ID，以及有限系数导致的像元溢出均阻断发布。错误定位至 XML 字段、配置字段或结果波段，溢出后的暂存目录已清理。

## 接口与范围

`resolve_reflectance_coefficients(mapping)` 返回红光与近红外的原始系数。Landsat 为 `MultiplyAddCoefficients(scale, offset)`，Sentinel-2 为 `QuantificationCoefficients(quantification, dn_offset)`。`scale_product_reflectance(source, destination, *, registry)` 返回 `ReflectanceResult(metadata, evidence)`，要求目的父目录存在。成果是按 256 × 256 分块写入的双 Float64 GeoTIFF，第一带 `red`、第二带 `nir`，单位均为无量纲 `reflectance`，NoData 为 NaN，GDAL scale/offset 为 `1/0`。

`GEOPILOT_REFLECTANCE` 域中的 `CALIBRATION` JSON 与 `evidence` 对应。记录产品完整键、产品与可选 granule 标识、配置 ID/版本、原生文件、输入和输出波段索引、实际系数和字段路径。光谱定标保留有效的负反射率。QA 分类、NDVI 和正式方法入口分别由后续任务交付。专项使用标准结构合成 XML 与真实 GeoTIFF，提供 T10/T11 的定标像元证据。完整固定案例随 P8 阶段运行记录验收。
