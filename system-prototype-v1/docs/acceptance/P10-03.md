Agent-E 工作项由 Agent-A 与主控实施，建议 `REVIEW`。P10-01、P10-02 和 P5 基础工作台已验收。V2.0 §9.4 的脚本试跑使用既有本机运行器，工作台提供独立的结果浏览入口。[前置验收](../../plans/06_PROGRESS/ACCEPTANCE_LOG.md)

## 实现与接口

工作台头部进入 `?view=scripts`。脚本页按运行编号展示实际脚本版本、执行状态、退出码、日志及输出。已打开的运行编号保存在 `script_run` 查询参数中。刷新按钮重新读取本机记录。`RESULT_PENDING` 表示进程日志存在且终态尚未发布。

| 本机只读接口 | 返回 |
|---|---|
| `GET /api/script-runs` | 独立脚本目录中的已发布快照及其状态。 |
| `GET /api/script-runs/{id}` | 确切快照版本、执行明细、日志可用性及输出清单。 |
| `GET /api/script-runs/{id}/log` | 完整实际日志。`tail` 可读取末尾 1–1000 行，最多 128 KiB。 |
| `GET /api/script-runs/{id}/outputs/{index}/file` | 按已记录输出索引下载原始字节。 |
| `GET /api/script-runs/{id}/outputs/{index}/preview` | 可支持矢量输出的 WGS84 GeoJSON，供本机 MapLibre 展示。 |

接口复用脚本快照校验和运行结果读取。下载使用打开后的普通文件描述符，核对清单记录的大小。已丢失或被链接替换的文件保留清单位置和不可读状态。矢量预览使用已检查的文件字节及现有 WGS84 预览转换。脚本运行和正式 SQLite `run`、`artifact` 记录各自独立。

新增 `src/geopilot/api/script_routes.py`、`tests/api/test_script_runs.py`、`frontend/src/features/scripts/` 内的页面、样式、API 客户端与组件测试、本报告及证据。主控在 `src/geopilot/api/app.py`、`frontend/src/App.tsx` 和工作台页接入路由与导航。
