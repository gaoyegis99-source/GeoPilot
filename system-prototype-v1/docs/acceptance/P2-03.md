# P2-03 参数与枚举规范化

主控实现，前置 P2-01 已验收。`normalize_parameters` 按已选工具契约展开默认值，校验类型、范围和枚举。显式数量按已登记的同量纲单位换算，整型要求结果精确为整数。未知字段与无效参数提供 `INVALID_PARAMETER` 及字段位置。

先写 `tests/tools/test_parameter_normalizer.py`，指定测试初次因生产模块不存在，退出 `2`。增加 `src/geopilot/tools/parameter_normalizer.py` 后，`python -m pytest tests/tools/test_parameter_normalizer.py -q` 实跑 `13 passed in 0.22s`，无失败或跳过。[JUnit](../../artifacts/test-results/p2-03-junit.xml)

实际读取 `config/tools/qgis-buffer.yaml` 并验证 `0.5 kilometer` 归一为 `500 meter`。测试覆盖面积换算、整型边界、枚举大小写、严格布尔值、缺项、额外字段、跨量纲拒绝与默认 JSON 隔离。角度单位换算使用 IEEE 双精度 π；坡度百分比与角度是不同量纲，需要对应算法显式转换。工具实现参数名与具体枚举编码由执行适配配置负责。
