# P9-05 结构化模型输出解析

状态 REVIEW，待主控验收。执行角色 Agent-G。

`parse_model_response(response, *, request)` 读取 `ModelResponse.text`，按同一 `ModelRequest` 的候选快照核对精确方法版本、选项名和枚举值，返回 `ParsedModelSuggestion`。必填字段为 `method`、`goal`、`options` 和 `missing`，另有可选文字 `explanation`。模型输出携带 `steps` 等未知字段、重复 JSON 键、非有限数或未知候选时返回 `ModelResponseError`。错误的 `code`、`field` 和 `message` 使用固定分类与安全字段位置。说明文字无效时清空该字段并记录 `explanation_issue`，其余有效字段仍可用于后续本机校验。[回复 JSON Schema](../../artifacts/schemas/p9-model-response.schema.json)
