# P5-03 方法目录

Agent-F 实施，建议 `REVIEW`。方法目录逐项展示 `GET /api/methods` 返回的版本。展开条目可查看描述、输入角色与类型。不可用条目可展开诊断，保留服务返回的原始原因及字段。可用条目返回精确方法引用供任务选择。[原子任务](../../plans/04_TASKS/P5/P5-03.md)

`MethodCatalogPanel` 由调用方传入 `methods`、当前 `selected`、`onSelect` 以及可选的 `loading` 和 `error`。选择事件返回 `{id, version}`。根组件通过既有 `workbenchApi.methods` 拉取目录并持有选择状态。[组件](../../frontend/src/features/methods/MethodCatalogPanel.tsx) · [样式](../../frontend/src/features/methods/method-catalog.css) · [测试](../../frontend/src/features/methods/MethodCatalogPanel.test.tsx)

## 实际验证

在 `frontend/` 下执行以下命令。

```bash
npm test -- --run src/features/methods/MethodCatalogPanel.test.tsx
npm test -- --run
npm test -- --run src/pages src/features/assets src/features/methods
npm test -- --run src/features/methods/MethodCatalogPanel.test.tsx --reporter=default --reporter=junit --outputFile.junit=../artifacts/test-results/p5-03-junit.xml
npm run build
```

先写测试。组件缺失时 Vitest 实际退出 `1`。专项最终 `4 passed`，工作台、资产和方法的联合回归 `11 passed`，两者均退出 `0`。TypeScript/Vite 构建退出 `0`。全量前端运行当时有并行开发中的 `RunPanel` 和 `ProblemDetails` 测试找不到生产模块，退出 `1`，已收集的 11 项测试通过。[专项 JUnit](../../artifacts/test-results/p5-03-junit.xml)

从现有回环代理 `http://127.0.0.1:5173/api/methods` 和隔离的本机 Uvicorn 实例 `http://127.0.0.1:8735/api/methods` 实际读取目录，均 HTTP 200。分别对照本机加载的 YAML，顺序和六个 `id/version` 完全一致。属性筛选 v1 在常规环境可用，显式指定不存在的 QGIS 路径后返回 `TOOL_UNAVAILABLE` 与 `steps.0.tool`。两次读取中空间筛选 v1 均可用，三个输入角色及类型一致。[HTTP 记录](../../artifacts/smoke/p5-03/methods-http.json)

以 Chromium `141.0.7390.37` 实跑工作台 `5173` 和指向隔离 API 的 Vite `5174`，核对真实接口响应与全部六条 DOM 记录。两种环境均通过键盘打开空间筛选详情、看到真实输入角色并选择 v1。常规环境显示道路 v1 的缺失工具绑定诊断，隔离环境显示属性筛选缺失 QGIS 的诊断，两处选择按钮均禁用。两种视口均无横向溢出或页面错误。隔离服务已停止。[桌面目录](../../artifacts/smoke/p5-03/methods-desktop.png) · [窄屏不可用诊断](../../artifacts/smoke/p5-03/methods-unavailable.png) · [浏览器记录](../../artifacts/smoke/p5-03/methods-browser.json)
