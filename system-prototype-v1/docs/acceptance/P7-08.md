# P7-08 栅格阈值提取

状态 REVIEW，待主控验收。执行角色 Agent-B。

`classify_raster(source, destination, *, threshold)` 读取单波段真实 GeoTIFF，返回重开的分类栅格元数据。`ThresholdSpec` 校验至少一个阈值区间，类别为严格整数 1–254，端点为有限数值或 `null`，两端开闭分别显式声明。两个区间可以共用类别，覆盖范围须互斥。同值双闭区间代表一个精确值。

分类用 GDAL 波段的 scale 和 offset 解释物理值。有效像元按区间赋值，落在区间之外的有效像元为 0，源掩膜或非有限值对应 NoData 255。UInt8 成果沿用原栅格尺寸、CRS 和仿射，以 256×256 像元块读取和写入。标签记录完整区间、源单位及定标、类别约定和 `RESAMPLING=none`。输出经重开核对后以新文件发布，拒绝同名文件或栅格伴随文件。

`python-dem-threshold` v1 通过正式 Python 步骤入口接收 `terrain_raster:raster_terrain` 和 `threshold` JSON，输出 `threshold_regions:raster_classification`。实际步骤日志记录使用的区间、CRS、像元大小和类别约定。
