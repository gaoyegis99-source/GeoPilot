## 净目录复跑命令

在原型根目录准备干净副本。以下使用本机已经配置的原生 `qgis_process`。本次实测把开发机包装器和配套两个可执行文件显式复制到临时目录后，将 `p11_qgis` 指向复制的入口。[本机包装器前置](../baseline/ENVIRONMENT.md#p0-03-cli-恢复记录)

```bash
p11_source="$PWD"
p11_directory=$(mktemp -d /tmp/geopilot-p11-07.XXXXXX)
mkdir -p "$p11_directory/project" "$p11_directory/state"
rsync -a --exclude='__pycache__/' --exclude='*.pyc' --exclude='node_modules/' \
  --exclude='dist/' --exclude='.pytest_cache/' --exclude='.env*' \
  src config frontend scripts tests plans pyproject.toml requirements.txt requirements-test.txt \
  "$p11_directory/project/"
cd "$p11_directory/project"
python3.13 -m venv .venv
PIP_CONFIG_FILE=/dev/null .venv/bin/python -m pip install --index-url https://pypi.org/simple \
  --no-cache-dir --only-binary=:all: -r requirements-test.txt
.venv/bin/python -m pip check
(cd frontend && npm ci --cache "$p11_directory/npm-cache" --include=dev --no-audit --no-fund && npm run build)

p11_qgis=/absolute/path/to/qgis_process
GEOPILOT_PYTHON="$PWD/.venv/bin/python" GEOPILOT_QGIS_PROCESS="$p11_qgis" \
  PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONDONTWRITEBYTECODE=1 \
  bash scripts/test.sh tests/smoke tests/golden tests/remote_sensing/test_product_pack.py -q -p no:cacheprovider \
  --basetemp "$p11_directory/smoke-tests" --junitxml="$p11_directory/smoke-junit.xml"

.venv/bin/python -B "$p11_source/artifacts/smoke/p11-07/verify_startup.py" \
  --project "$PWD" --state "$p11_directory/state" --qgis-process "$p11_qgis" \
  --output "$p11_directory/live-road" --backend-port 48000 --frontend-port 45173
```
