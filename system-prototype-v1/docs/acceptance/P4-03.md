# P4-03 单运行调度循环

2026-11-11，主控验收。新增 `src/geopilot/scheduler/loop.py` 与 `tests/scheduler/test_scheduler.py`。SQLite 写事务领取最早的 `NOT_STARTED` 运行，并发布 `RUNNING` 后调用执行器。正在执行或检查时保留队列。执行器异常保留失败原因，结束信号可在空闲等待和两次调度之间生效。启动恢复以调用方验证旧受管进程已停止为前提，区分计算中断与检查中断，后者保留执行成功。进程终止和服务生命周期随后续任务接入。

先行测试退出 2，缺少调度模块。运行 `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest tests/scheduler/test_scheduler.py -q --junitxml=artifacts/test-results/p4-03-junit.xml` 退出 0，4 项通过。两个线程从真实 SQLite 同时领取仅一个成功。实际查询验证状态可见、队列继续、恢复拒绝与恢复后状态、检查状态和停机信号。调度测试用可控回调模拟异常，真实 GIS 步骤由 P4-04 验收。连同运行模型和创建服务复跑 22 项通过。[专项 JUnit](../../artifacts/test-results/p4-03-junit.xml)
