# P8-01 传感器产品配置模型

2026-11-12 主控签收。执行角色 Agent-C。主控联合复跑 128 项通过。[主控 JUnit](../../artifacts/test-results/p8-01-root-junit.xml)

`SensorProductConfig` 保存配置 ID 和正整数版本，以及传感器、产品级别和处理版本的精确键。`.ref` 返回 `SensorConfigRef`，`.key` 返回 `SensorProductKey`。处理版本保留字符串中的前导零和小数点。配置同时校验波段角色、逐波段定标、质量规则和来源日期。

- Landsat 8 与 Landsat 9 分别声明 Collection `02` 的 `L2SP` 和 `L2SR`。红光和近红外用 30 米 `SR_B4/SR_B5`，乘加字段都从 `LEVEL2_SURFACE_REFLECTANCE_PARAMETERS` 选择。质量策略排除 `QA_PIXEL` 位 0–5，另按 `QA_RADSAT` 位 3、4、11 排除相应波段饱和和地形遮蔽。[USGS 产品指南 v6.0](https://www.usgs.gov/media/files/landsat-8-9-collection-2-level-2-science-product-guide) · [USGS 质量波段](https://www.usgs.gov/landsat-missions/landsat-collection-2-quality-assessment-bands)
- Sentinel-2 MSI `L2A` 基线 `05.11` 使用 10 米 `B04/B08` 和 20 米 `SCL`。量化值和 DN 偏移来自产品 XML，红光及近红外偏移分别选择零基 `band_id` 3 和 7。SCL 记录完整 0–11 类，其中类别 2 表示地形投射阴影。原型的保守质量策略保留植被、非植被和水体三类 4、5、6。[Copernicus 产品规范 v15.0](https://sentiwiki.copernicus.eu/__attachments/1692737/S2-PDGS-CS-DI-PSD%20-%20S2%20Product%20Specification%20Document%202024%20-%2015.0.pdf?inst-v=0f5b269b-1e8e-45fa-879c-4de81a2a8e80) · [处理基线说明](https://sentiwiki.copernicus.eu/web/s2-processing)

定标配置记录产品元数据字段，具体 DN 乘加、量化及偏移值由后续步骤从产品读取。模型拒绝缺项、非法类型、冲突波段、越界或重复的质量位，以及未声明的有效类别。
