# P1-02 DataAsset 公共模型

- 日期：2026-11-11（Asia/Shanghai）
- 实施：Agent-A
- 建议状态：`REVIEW`
- 依赖：P0-01 已验收，[P1-01](P1-01.md) 已由主控验收

`geopilot.domain.data_asset` 提供不可变的 `DataAsset`、`DataAssetRef`、`FileSource` 和三种元数据类型。资产与引用版本均为严格正整数。`DataAsset.ref` 返回同一资产的精确版本引用。创建时间必须带时区，来源仅包含本机绝对路径、可选图层和文件修改时间。路径保留为 `Path`，JSON 中为字符串。`postgis_snapshot` 仅能描述本机快照文件，数据库连接信息由后续适配任务处理。

矢量和栅格的未知 CRS 以 `null` 保存，要求 `CRS_UNKNOWN` 原因。范围与仿射采用固定长度坐标数组。栅格逐波段数组的长度与波段数一致。NoData 未设置时为 `null`，非有限值使用 `"nan"`、`"inf"`、`"-inf"`，数值 NoData 保留为 JSON 数字。未知波段名、单位或尚未统计的字段缺失数可保留为 `null`。表格元数据保留行数、驱动和字段。

## 本机 JSON Schema 示例

`DataAsset.model_json_schema()` 的必需字段为 `id`、`version`、`source_type`、`source`、`metadata`、`fingerprint`、`availability` 和 `created_at`。`version` 为 `integer`，`exclusiveMinimum` 为 `0`。`metadata` 的 `kind` 判别值映射到 `$defs/VectorMetadata`、`$defs/RasterMetadata`、`$defs/TableMetadata`。`DataAsset` 和 `FileSource` 均禁止额外属性。绝对路径、未知 CRS 原因和波段数量关联由模型运行时验证。

以下为人工来源的 `DataAsset.model_dump_json()` 输出。`source`、本机范围和指纹供本机使用。外部模型所需摘要按 V2.0 §8.8 使用独立允许字段结构。

```json
{
  "id": "asset-roads",
  "version": 2,
  "source_type": "local_file",
  "source": {
    "path": "/work/geopilot/data/roads.gpkg",
    "layer": "roads",
    "modified_ns": null
  },
  "metadata": {
    "format": "GPKG",
    "crs": null,
    "bounds": null,
    "issues": ["CRS_UNKNOWN"],
    "kind": "vector",
    "geometry_type": "LineString",
    "feature_count": 3,
    "fields": [{"name": "road_name", "dtype": "str", "missing_count": 1}]
  },
  "fingerprint": "sha256:example",
  "availability": "AVAILABLE",
  "created_at": "2026-11-11T00:45:00Z"
}
```

对应 `DataAsset.ref` 序列化为 `{"asset_id":"asset-roads","asset_version":2}`。
