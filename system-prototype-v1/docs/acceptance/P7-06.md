# P7-06 DEM 坡向

状态 ACCEPTED，主控验收。

`calculate_aspect` 使用共享 Horn 3 × 3 梯度，按本机米制比例使用东、北上坡分量。输出下坡方位角，网格北为 0°、顺时针、区间 [0°, 360°)。平地、边缘及邻域含无效像元的位置写 NoData。GeoTIFF 保留网格、CRS 与度单位。极接近北的方位角若按 Float32 舍入到 360°，归到 0°。
