## 实现与接口

`validate_method(method, *, registry, registered_rules, source=None)` 接收 `MethodDefinition` 或原始配置映射，返回有序 `tuple[MethodIssue, ...]`。每个问题保留错误代码、点分字段、消息和可选配置文件路径。校验器先用 `MethodDefinition` 检查字段与类型，再按步骤检查键、工具精确版本和可用性、必需及额外端口、输入来源声明类型与输出类型。

参数检查必需绑定与选项引用，采用已有 `normalize_parameters` 检查字面量、显式单位和已声明的选项默认值。工具契约允许省略的参数及自带默认值的参数可由后续请求规范化处理。预期成果必须有唯一角色及明确的步骤、输出和类型。方法 `check_rules` 使用传入的已登记名称校验。
