# P7-12 正式栅格原像元查询

2026-11-12 主控签收。A 实现正式 GeoTIFF 的原像元查询和 HTTP 接入，B 实现 MapLibre 点击与结果展示，F 构造真实运行样本并独立核对浏览器请求。主控复跑联合测试与独立 GDAL 对照。

`GET /api/artifacts/{id}/value` 接收 WGS84 经纬度、波段及可选原始指纹。服务复核正式文件组，把坐标转换至原 CRS，按原仿射定位零基行列，在命中的一个像元读取存储值和原掩膜。有效值、NoData 和范围外各有明确状态。有效值 0 保留，超过 JavaScript 安全范围的整型值用精确十进制文本。波段 scale、offset 和单位同时返回供解释。[原像元查询](../../src/geopilot/artifacts/value_query.py) · [API](../../src/geopilot/api/artifact_routes.py)

地图点击发送确切成果 ID 与内容指纹。切换配色只刷新预览，后发点击结果优先。结果区展示原值、行列、源坐标和单位，保留矢量成果选择。[地图交互](../../frontend/src/features/map/MapPanel.tsx)

## 实际验证

- 后端专项 22 项通过。真实登记的 TIFF 覆盖零值、NoData、非有限值、旋转网格、半开边界、64 位整数和来源变化。探针确认实际只读一个 1×1 像元窗口，范围外不读取像元。[专项 JUnit](../../artifacts/test-results/p7-12-backend-junit.xml)
- 主控用独立 GDAL 3.10.2 重开两份正式 TIFF。依据各自的原始网格选取全部九个像元中心及一个范围外点，两份成果共 20 条真实 HTTP 响应与 GDAL 的值、掩膜及行列一致，转换回源坐标的误差小于 0.00000002 米。[独立 GDAL 对照](../../artifacts/test-results/p7-12-gdal-http-comparison.json)
- Chromium 用真实工作台验证 45° 基线、带孔成果 65.90515899658203° 和 76.36698150634766°、中心 NoData 及分类值 4。七条实际请求逐一按原 TIFF 重开核对。换灰度未发取值请求，故意迟到的真实响应未覆盖最新点击。三份 TIFF 的 SHA-256 和修改时间一致，外链与页面错误为 0。[带孔七步样本](../../artifacts/smoke/p7-12/fixture.y8l51gmc/fixture.json) · [浏览器记录](../../artifacts/smoke/p7-12/run.vLKUuq/browser.json) · [逐点对照](../../artifacts/smoke/p7-12/run.vLKUuq/independent-sample-checks.json)

- 主控联合 DEM 七步、成果检查、预览和原值接口 55 项通过。前端 66 项通过，TypeScript 和 Vite 构建成功。矢量定位会清除旧栅格查询并保留既有矢量拾取。[后端联合 JUnit](../../artifacts/test-results/p7-12-joint-junit.xml) · [前端 JUnit](../../artifacts/test-results/p7-12-frontend-junit.xml)

## 复现入口

```bash
python -m pytest tests/artifacts/test_value_query.py -q
python -m pytest tests/artifacts/test_value_query.py tests/preview tests/methods/test_dem_terrain_method.py tests/checks/test_raster_checks.py -q
(cd frontend && npm test -- --run && npm run build)
node artifacts/smoke/p7-12/verify-browser.mjs artifacts/smoke/p7-12/fixture.y8l51gmc/fixture.json
```

浏览器复跑使用本机 Playwright。可通过 `GEOPILOT_PLAYWRIGHT_MODULE` 指向安装的模块入口。像元接口首轮联合测试的读取探针未透传 Rasterio 数据集，修正测试探针后最终联合通过。生产读取实现保持原单像元窗口。
