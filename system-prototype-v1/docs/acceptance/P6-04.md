`spatial-select-and-clip` v1 锁定 `apply_spatial_relation` 后接 `clip_back_to_analysis_extent`。`targets` 接收矢量目标，`relation_area` 和 `analysis_extent` 分别绑定面范围。第一步按 `spatial_relation` 调用已验收的 `intersects` 或 `within`，写出命名成果 `targets`，其中保留选中行的完整原几何、属性与 `source_feature_id`。第二步只接收该命名成果与已选裁剪范围。[方法配置](../../config/methods/spatial-select-and-clip.v1.yaml) · [选择契约](../../config/tools/python-select-spatial-relation.yaml) · [裁剪契约](../../config/tools/python-clip-vector-to-extent.yaml)

裁剪按范围面并集取得非空交集，保留每条存活行的 `source_feature_id`。成果 `clipped_targets` 使用通用 GeoPackage `GEOMETRY` 层，接触产生的线、点及可能的混合几何集合可保存在同层。多部件交集仍是一条要素。成果 `original_targets` 保存同一批存活行的原几何与属性，供质心和最大重叠使用。空交集在两份成果中都没有该行，全部为空时仍发布可打开的空图层。裁剪成果的面分量可作为后续面积输入。[选择实现](../../src/geopilot/gis/tools/select_spatial_relation.py) · [裁剪实现](../../src/geopilot/gis/tools/clip_vector_to_extent.py) · [GeoPackage 交接](../../src/geopilot/gis/tools/vector_step_files.py)
