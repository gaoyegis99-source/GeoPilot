`inspect_crs` 用 PyProj 解析源元数据的 CRS，返回原始 `pyproj.CRS`、两条水平轴的单位和线性单位的米换算因子。地理 CRS 的角度轴保留单位名，米换算因子为空。两轴都需有匹配的单位类型和换算因子。未知或无法解析的 CRS 返回 `CRS_UNKNOWN`。非水平空间和不适合平面米制的坐标系返回 `MEASUREMENT_POLICY_REJECTED`。错误保留原观察值、字段和原因。

平面米制检查拒绝地理 CRS、英尺轴以及 Web Mercator。识别依据包括与 EPSG:3857 或历史 EPSG:3785 的等价性、EPSG:1024 投影方法，以及 WKT 未保留编号时的 Pseudo-Mercator 方法名。[EPSG:3785 记录](https://epsg.org/crs_3785/Popular-Visualisation-CRS-Mercator.html) · [PROJ 投影方法](https://proj.org/en/stable/development/reference/cpp/operation.html)

`validate_crs_operation` 区分未知源显式设置和已知源重投影。两个操作均要求目标 CRS 已知。函数只检查前提，独立测试核对了源文件内容及 CRS。范围适用性、比例变形、测地和等积能力由后续任务验证。
