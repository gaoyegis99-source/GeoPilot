# P5-04 方法驱动表单

Agent-F 实施，建议 `REVIEW`。表单按已登记方法的精确版本呈现输入角色和关键选项。资产选项按角色类型、实际几何类型及登记可用状态筛选。服务返回的角色判定仅在方法版本和所选资产版本均吻合时显示。[原子任务](../../plans/04_TASKS/P5/P5-04.md)

## 交付与接口

`MethodForm` 接收 `method`、`assets`、`goal`、`inputs`、`options`、`context` 与编辑回调。`onPrepare` 返回目标、精确方法、选中的精确资产引用和声明内的选项。更换方法版本时重置组件的编辑状态，根组件重置该方法的角色和选项。缺项就地显示，目标非空时允许生成部分草稿，供服务返回问题。无效输入阻断提交。

枚举、整数、数值、文本、布尔、JSON 和引用均使用与定义相符的控件。默认值包括显式 `false` 和 `0`。引用按选择值和步骤绑定判定必填，未激活且未绑定的引用从表单及提交中省去。数值显示定义单位并校验上下限，已保存的显式 `{value, unit}` 保留其单位，换算由后端处理。未具体定型的 `user_defined` 和 `user_selected` 可编辑为 JSON 值。
