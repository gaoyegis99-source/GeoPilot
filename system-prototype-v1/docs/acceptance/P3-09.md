`save_draft` 在同一 SQLite 事务保存任务和新草稿版本，校验传入的上下文与任务、目标、方法及资产版本一致。`load_plan` 按精确方案编号与版本重读，并核对行的身份与状态和 JSON 快照一致。`geopilot.persistence.plan_repository.insert_draft(connection, plan, *, context=None)` 支持调用方在同一写事务内分配版本后插入，事务提交由调用方管理。

`confirm_plan` 先检查保存的 `issues`，再核对确切方法和工具、注册规则、实际资产版本与前提、关键选项和步骤绑定。V2.0 §7.9 的空规则清单返回 `MISSING_CHECK_RULES`。未注册的检查或前提按字段返回 `PlanConfirmationError.issues`。通过 P3-08 生成规范化步骤，保留原关键选项。短写事务比较草稿原 JSON，再同时保存确认状态和完整快照。重复或并行确认读取已发布的同一版本。
