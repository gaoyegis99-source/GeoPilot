# P4-02 运行创建服务

2026-11-11，主控实施。依据 V2.0 §7.6、§8.6 和 P4-02。新增 `src/geopilot/runs/service.py`、`tests/runs/test_run_creation.py` 和专项 JUnit。

`create_run` 读取指定的已确认版本，复用资产重开与文件组暂存，写入包含原始确认快照、实际图层及运行内引用的请求。发布成功后返回新编号，初态为 `NOT_STARTED / NOT_CHECKED`。已有等待执行、正在执行或正在检查的运行时返回该编号。并发受理在 SQLite 写事务中复核活动记录，未发布的目录会清理。受理本身只准备运行。

先行测试退出 2，缺少受理模块。实现后运行 `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest tests/runs/test_run_creation.py -q --junitxml=artifacts/test-results/p4-02-junit.xml`，退出 0，5 项通过。测试使用真实 GeoPackage、登记版本及 SQLite 确认快照，覆盖草稿和未知版本、指纹变化、精确快照与独立目录、双线程受理和数据库写入失败清理。 [专项 JUnit](../../artifacts/test-results/p4-02-junit.xml)
