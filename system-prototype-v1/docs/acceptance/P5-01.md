# P5-01 工作台路由与基础布局

Agent-F 实施，建议 `REVIEW`。工作台从 `/` 进入。桌面左侧为数据，中间为地图，右侧依次为任务、方案、运行和结果。窄屏沿相同顺序纵向显示。底部规则检查默认收起，警告和未通过摘要仍可见。执行状态在运行区独立显示。[原子任务](../../plans/04_TASKS/P5/P5-01.md)

## 组件接口

`WorkbenchPage` 通过七个可选 React 插槽接收实际功能组件。`App` 是页面的组合入口，`executionStatus` 和 `checkStatus` 分别接收 P4 执行与检查枚举。地图插槽有随容器伸展的定位区，CSS 变量集中在 `styles.css`。[页面组件](../../frontend/src/pages/WorkbenchPage.tsx) · [样式](../../frontend/src/styles.css)

| 属性 | 区域 |
|---|---|
| `assets` | 数据 |
| `map` | 地图 |
| `task` | 任务 |
| `plan` | 方案 |
| `run` | 运行 |
| `artifacts` | 结果 |
| `checks` | 规则检查明细 |

当前入口显示空工作区。导入数据、确认方案和开始运行在各自功能接入前禁用。MapLibre 图层留待 P5-08 接入，当前地图为空态网格。页面使用本机字体，不请求外部字体或瓦片。

## 实际验证

在 `frontend/` 下使用 Node `v22.23.1`、npm `10.9.8`。

```bash
npm install --prefer-offline --registry=https://registry.npmjs.org --no-audit --no-fund --fetch-retries=1 --fetch-timeout=15000
npm test -- --run
npm run build
npm test -- --run --reporter=default --reporter=junit --outputFile.junit=../artifacts/test-results/p5-01-junit.xml
npm run dev -- --port 5173 --strictPort
```

先写组件测试，页面模块缺失时实际退出 `1`。实现后 Vitest `4 passed`，退出 `0`。TypeScript 类型检查和 Vite 生产构建退出 `0`，Vite `built in 204ms`。将清单与锁文件复制到新临时目录后用 npm `ci --offline` 安装也退出 `0`。npm 输出一条间接依赖 `whatwg-encoding` 的弃用提示。[专项 JUnit](../../artifacts/test-results/p5-01-junit.xml)

本机 Chromium `141.0.7390.37` 实际请求 `http://127.0.0.1:5173/` 返回 HTTP 200。验证了桌面 `1440 × 900` 的三栏及底部检查区，窄屏 `390 × 844` 的纵向顺序，两个视口均无横向溢出、页面错误或外部资源请求。键盘 Enter 可展开和收起规则检查，确认与运行按钮位于各自区域。测试使用本机已有的 Playwright 1.56.1 与配套浏览器。[桌面截图](../../artifacts/smoke/p5-01/workbench-desktop.png) · [窄屏截图](../../artifacts/smoke/p5-01/workbench-mobile.png) · [浏览器记录](../../artifacts/smoke/p5-01/preview.json)
