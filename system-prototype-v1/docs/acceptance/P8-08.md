# P8-08 两期 NDVI 差值

2026-11-12 主控签收，主控联合 228 项通过。执行角色 Agent-B。[主控 JUnit](../../artifacts/test-results/p8-08-root-junit.xml)`write_ndvi_change(aligned, destination)` 读取 P8-07 的 `first_ndvi` 和 `second_ndvi` Float64 波段，核对已知 CRS、仿射网格、单位 `1`、恒等 GDAL 缩放、NaN NoData 与实读掩膜。两带共同有效值在 `[-1, 1]` 内时，逐块计算第二期减第一期。输出同格单带 Float64 `ndvi_change`，单位 `1`，共同无效处为 NaN。[实现](../../src/geopilot/remote_sensing/change.py)

`NdviChangeResult(metadata, summary)` 返回重开的栅格元数据及实测统计。`GEOPILOT_NDVI_CHANGE.SUMMARY` 保存相同 JSON，方向为 `second_minus_first`，另记录总像元、共同有效、NoData、正值、负值、零值及最小值、最大值。全无效时最小值和最大值为 `null`。差值保持输入像元位置和有效零值。

```bash
python -m pytest tests/remote_sensing/test_change.py -q -p no:cacheprovider \
  --junitxml=artifacts/test-results/p8-08-junit.xml
python -m pytest tests/remote_sensing tests/gis/raster/test_window_io.py tests/gis/raster/test_clip_back.py \
  tests/data_adapters/test_raster_reader.py tests/application/test_run_inputs.py -q -p no:cacheprovider \
  --junitxml=artifacts/test-results/p8-08-joint-junit.xml
```

- 第二期原点向东偏移一格，经过真实 P8-07 最近邻对齐后逐像元比较。重开值为 `[[NaN, 0.5, -0.25, 0], [NaN, NaN, NaN, 0.75], [NaN, 2, -2, -0.0]]`，共同有效 7，NoData 5，正值 3、负值 2、零值 2，范围 `[-2, 2]`。输入两期 NDVI 和对齐文件指纹复核一致。
- 真实分离覆盖产生空交集，结果保留第一期网格和两个 NoData 像元。259 × 261 栅格的四块输出与手算矩阵完全一致，边界处 `-0.0` 仍是有效像元，符号保留。
- 三种实建的掩膜与 NaN 不一致情况均在实际读块时阻断，错误给出零基行列。可见越界值、错误波段顺序或 NoData、未知 CRS 和缺仿射均阻断。最后一块错误时清理暂存文件，正式目标与源文件保持原状。
