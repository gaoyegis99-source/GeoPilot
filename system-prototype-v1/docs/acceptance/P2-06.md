`validate_area(metadata, field=...)` 复用投影米制检查，保留 `CRS_UNKNOWN`，并以 `MEASUREMENT_POLICY_REJECTED` 拒绝不合适的测量 CRS、方法或范围。等积判定对照 PyProj 读取的 EPSG 方法编号与 PROJ 实际投影步骤，再由共享范围检查核对声明的适用区。通过时返回 `MeasurementDecision(method="equal_area", crs=metadata.crs, unit="square_meter")`。
