# P2-05 距离测量策略

主控于 2026-11-11 验收。策略复用 P2-04 真实 CRS 检查，要求米制、非 Web Mercator 的投影。PROJ 将输入范围反变换至 WGS84，并核对声明适用区。对 5×5 范围采样点计算 Tissot 主比例因子，两方向相对单位比例的偏差均须在 0.001 以内。这个阈值用于 P2 的采样适用性检查。通过时记录实际输入 CRS、`local_projected` 和 `meter`。测地线方式报告不可用，正式验证见 P6-09。

- 实现前执行 `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest tests/gis/test_distance_policy.py -q`，退出 2，缺少策略模块。
- 执行 `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest tests/gis/test_distance_policy.py tests/gis/test_projection_coverage.py -q --junitxml=artifacts/test-results/p2-05-junit.xml`，12 项通过。真实 GeoPackage 覆盖经纬度、3857、32650 和 3395 道路，另验证 UTM 适用区外、缺范围和未声明适用区。 [专项 JUnit](../../artifacts/test-results/p2-05-junit.xml)
- 执行 `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest tests/gis -q --junitxml=artifacts/test-results/p2-measurement-junit.xml`，39 项通过。 [联合 JUnit](../../artifacts/test-results/p2-measurement-junit.xml)
