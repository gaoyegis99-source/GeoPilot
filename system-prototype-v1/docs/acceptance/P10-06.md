## 实现与接口

`refresh_postgis_snapshot(database_path, destination, *, conninfo, source, layer="snapshot") -> DataAsset` 以 `PostGISSource.source_key` 找到已有选择，为同一资产 ID 追加版本。每次明确重导出均保存独立 GeoPackage 和导出时点。并发版本号按 SQLite 提交顺序分配。`import_postgis_snapshot` 保持首次登记语义。来源键由连接别名、schema、表、几何列、属性列和筛选确定，源库连接由本机调用方提供。

复用 P10-05 的只读一致性导出与真实重开。导出和指纹复核在私有临时目录完成。`BEGIN IMMEDIATE` 内复核来源版本和历史登记路径，在确认目标空闲后原子发布文件，再插入并复读新版本。写入被拒或提交失败时撤回本次文件。旧版本文件即使被移走，其登记路径仍保留给原版本。正式方案继续按精确 `DataAssetRef` 解析与暂存。

修改 `src/geopilot/data/postgis_import.py`，新增 `tests/data_adapters/test_postgis_versioning.py`、本报告、专项 JUnit 和实际隔离运行证据。复用现有资产表与来源字段。
