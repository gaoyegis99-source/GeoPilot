# P2-09 Python 最小执行适配器

2026-11-11（Asia/Shanghai），Agent-F 提交 `REVIEW`。依据 V2.0 §7.7、§8.9、§12.3.3 和[步骤执行交接](../../plans/01_ARCHITECTURE/07_STEP_PROTOCOL.md)。

`run_python(request, *, registry, workdir, implementations, timeout=60)` 使用精确登记的工具版本。调用方将工具实现标识映射到受信本机脚本的绝对路径。共享适配器校验请求、参数、文件位置并保存 `request.json`。Python 进程使用当前解释器，以运行目录为工作目录，通过独立参数接收 `--request` 和 `--result`，进程日志保留实际参数、stdout、stderr 和退出码。

脚本将 `outputs` 写入步骤内独立的 `python-result.json`。每个角色可以对应相对路径字符串，或 `{path, layer?}`，并可附 `environment` 的字符串版本映射。角色、路径和图层须与请求一致。该文件使用保留位置，已有文件会拒绝运行。共享适配器重新打开实际成果，写入统一 `result.json`。子进程退出 0 且缺文件或角色时为 `OUTPUT_MISSING`，清单结构错误、不一致或文件不可读时为 `OUTPUT_INVALID`。未配置脚本、进程非零退出、超时分别保留独立错误。

```bash
python_runner_test_tmp=$(mktemp -d /tmp/geopilot-p2-09.XXXXXXXX)
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONDONTWRITEBYTECODE=1 \
  python -m pytest -p no:cacheprovider --basetemp "$python_runner_test_tmp/pytest" \
  tests/runners/test_python_runner.py -q --junitxml=artifacts/test-results/p2-09-junit.xml
```
