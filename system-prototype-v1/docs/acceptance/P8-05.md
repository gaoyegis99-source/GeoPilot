# P8-05 质量掩膜生成

2026-11-12 主控签收。执行角色 Agent-B。最终主控联合 177 项通过。[主控 JUnit](../../artifacts/test-results/p8-04-p8-05-root-junit.xml)`write_quality_mask(source, destination, registry=...)` 用产品配置和实际波段映射按块读取 DN。它将红光和近红外的填充判定、各源波段的 GDAL 有效掩膜、质量位或 SCL 类别取交集，写入同一 CRS、仿射变换、尺寸的单波段 UInt8 GeoTIFF。波段名为 `quality_mask`，`1` 表示有效，`0` 表示无效，NoData 为 `None`。[实现](../../src/geopilot/remote_sensing/quality_mask.py)

`QualityMaskResult` 返回重开后实读的元数据、`SensorConfigRef`、有效和无效像元数，以及各分类质量角色的未知类别计数。未知类别计数以该质量波段可读取且有效的 DN 为基数，与光谱或其他质量条件的无效计数可能重叠。`GEOPILOT_QUALITY_MASK` 标签记录原产品 ID、配置 ID/版本、各质量波段的产品代码、索引、原生文件、分辨率和重采样记录，以及像元计数。结果可用 `quality_mask == 1` 与光谱有效掩膜取交集供后续 NDVI 使用。

- Landsat 8 Collection 2 L2SP 的 4×5 手算矩阵为 8 有效、12 无效。逐位核对 `QA_PIXEL` 0–5 位和 `QA_RADSAT` 3、4、11 位，验证原 QA DN `0`、无关质量位和无关饱和位仍可有效。红光填充、近红外填充及显式 GDAL 掩膜各遮去预期像元。重开结果确认 0/1 均为存储值，源内容指纹相同。另用修改过的版本 2 配置核对坏位确由配置决定。[Landsat 配置](../../config/sensors/landsat-8-c2-l2sp.v1.yaml)
