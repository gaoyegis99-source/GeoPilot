# P9-01 模型供应商适配接口

Agent-G 工作项由 Agent-A 实施，建议 `REVIEW`。P3 和 P5 阶段已验收。接口依据 V2.0 §7.12 与 §8.8，支持先以固定返回验证模型建议链路。[前置验收](../../plans/06_PROGRESS/ACCEPTANCE_LOG.md)

`geopilot.llm.base` 提供 `ModelRequest(payload)`、`ModelResponse(text)` 与 `ModelProvider.generate(request, *, timeout) -> ModelResponse`。请求采用有限 UTF-8 JSON 对象，验证时与调用方对象解耦，序列化再次验证当前内容。响应保留原文本，供 P9-05 单独解析。请求摘要与外发内容检查分别接入 P9-02 和 P9-03。

`ModelProviderError` 提供 `code`、固定 `message` 和 `retryable`。超时、网络错误、服务不可用、限流和无效响应使用统一的 `MODEL_*` 编号。格式化错误隐藏请求内容和调用方字段。`MockModelProvider(response_text=...)` 或 `MockModelProvider(error_code=...)` 以固定配置返回相同文本或新的结构化错误。超时参数须为正的有限秒数。该供应商在进程内运行。

新增 `src/geopilot/llm/base.py`、`src/geopilot/llm/providers/mock.py`、`tests/llm/test_provider_contract.py`、本记录与专项 JUnit。
