# P9-02 允许外发的任务摘要

状态 ACCEPTED，主控验收。

`build_outbound_context(context, assets, *, protected_literals=())` 使用任务显式选择的精确资产版本，生成 `OutboundContext(goal, roles)`。角色包含就绪结论及类型化摘要。矢量与表格包含字段名、规范字段类型、数量与缺失比例；栅格包含宽高、波段数和两个独立分辨率值。摘要无文件、范围、仿射、连接、原始记录、资产指纹和本机判定消息。

已知精确来源与受保护样本值替换为本机引用。常见路径、连接串和数字坐标形式同样替换。复杂几何、原始结构化内容和控制字符要求本机清理。异常使用固定信息。调用方须提供已经识别的本地原始样本值作为 `protected_literals`，随后由 P9-03 验证最终请求。当前无网络调用。
