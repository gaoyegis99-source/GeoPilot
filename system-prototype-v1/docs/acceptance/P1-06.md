# P1-06 本机数据指纹

2026-11-11（Asia/Shanghai），Agent-F 提交 `REVIEW`。实现对应 V2.0 §3.1 `DATA-003`、§6.6、§7.1 和 P1-06 冻结契约。

`geopilot.data.fingerprint.fingerprint_file(path, *, strategy="content")` 返回 `FileFingerprint(digest, size_bytes, modified_ns)`。`digest` 为 SHA-256 的小写十六进制值，`size_bytes` 是源文件组总字节数，`modified_ns` 是组内最新的修改时间（纳秒）。

## 策略

| 策略 | 摘要输入 | 用途 |
|---|---|---|
| `content` | 固定策略版本前缀、每个文件的角色和长度、全部文件字节。主文件优先，旁车按角色排序。读取块最大 1 MiB。 | 登记与重开时比较内容身份。调整目录、统一改名或触摸 mtime 时，文件角色及内容相同则摘要相同。 |
| `metadata` | 独立策略前缀和每个成员的角色、大小、mtime_ns。 | 低成本变化提示。同大小和 mtime 的不同内容可能得到同一摘要。 |

角色使用 `main`，或 `stem`、`filename` 加实际旁车名后缀。源文件名及目录不写入摘要。角色和字节数以 `role:size` 加 NUL 编码。随后 `content` 消费明确长度的原始字节，`metadata` 消费 mtime 的十进制值和 NUL。读取前后比较成员集合、设备与 inode、大小、mtime_ns 和 ctime_ns。内容策略还对已打开文件句柄核对同样的信息。检测到变化或文件不可读时，`OSError` 携带可定位的路径。文件以只读方式打开。

## 文件组范围

同目录、相同文件名词干或主文件全名的已知旁车一并计算。匹配旁车后缀时接受 ASCII 大小写差异，角色保留后缀实际拼写。

| 主文件 | 纳入的旁车 |
|---|---|
| `.shp` | 同词干 `.shx`、`.dbf`、`.prj`、`.cpg`、`.qix`、`.sbn`、`.sbx`、`.qpj`、`.shp.xml`、`.idm`、`.ind`。[GDAL Shapefile 驱动](https://gdal.org/en/stable/drivers/vector/shapefile.html) |
| `.tif`、`.tiff`、`.cog` | 同词干 `.tfw`、`.tifw`、`.tiffw`、`.wld`、`.tab`、`.xml`、`.rpb`、`_rpc.txt`、`.rrd`。附在主文件全名后的 `.aux.xml`、`.msk`、`.ovr`、`.msk.ovr`、`.xml`。[GDAL GeoTIFF 驱动](https://gdal.org/en/stable/drivers/raster/gtiff.html#georeferencing) |
| `.gpkg` | 主文件全名加 `-wal` 或 `-journal`。`-shm` 属于 SQLite 临时共享内存索引，排除。[SQLite WAL](https://www.sqlite.org/wal.html) |
| 其他普通文件 | 仅主文件。 |

指纹表示文件组的字节身份。GeoPackage 检查点可能在逻辑数据相同的情况下重排主文件和 WAL，产生新摘要。P1 只支持表中列出的旁车范围，外部依赖和第三方旁车需要另行纳入。文件组读取依靠多次采样发现变化。仍在编辑的输入宜先稳定保存，运行前按设计重新核对指纹。实现通过操作系统文件接口访问普通文件，拒绝 URI、UNC 和 `/vsicurl/` 入口。操作系统已挂载的文件系统由系统配置负责。

```bash
fingerprint_test_tmp=$(mktemp -d /tmp/geopilot-p1-06.XXXXXXXX)
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONDONTWRITEBYTECODE=1 \
  python -m pytest -p no:cacheprovider --basetemp "$fingerprint_test_tmp/pytest" \
  tests/assets/test_fingerprint.py -q --junitxml=artifacts/test-results/p1-06-junit.xml
```

退出 `0`，`15 passed in 0.93s`，JUnit 解析为 15 项、0 失败、0 错误、0 跳过。验证多块文件与独立 SHA-256 一致、仅触摸时间戳和保留元数据改写、真实 Shapefile 文件组、GeoPackage WAL 提交。GeoTIFF 样本分别使用 `.tif` 和 `.cog` 扩展名，真实外部掩膜和改变仿射变换的 PAM 文件均影响摘要。用真实文件替换、增长和增加旁车验证读取期间的变化检测，另外检查缺失源、非普通文件、远程路径与无效策略。[JUnit](../../artifacts/test-results/p1-06-junit.xml)
