# P6-07 最大重叠归属

2026-11-11（Asia/Shanghai），Agent-F 提交 `REVIEW`。依据 V2.0 §5.4、§8.5 和 P2-06 等积测量规则。[P6-07 任务](../../plans/04_TASKS/P6/P6-07.md) · [等积规则证据](P2-06.md)

`assign_by_largest_overlap(targets, zones, *, boundary_tie="unassigned")` 接收裁前完整目标面与分区面，返回每个 `source_feature_id` 对应的分区 ID 或 `None`。复用质心和面积拆分的图层、ID、几何及 CRS 校验。两图层须使用同一已知适用等积米制 CRS。分区分别与完整面求交，只有有限正面积的交集进入比较。[实现](../../src/geopilot/gis/vector/boundary_assignment.py)

所有候选面积直接与最大值比较。与最大值的差不超过 `max(10⁻⁶ m², 10⁻⁹ × 最大面积)` 时视为并列。唯一最大正面积获得归属，多个最大候选、零面积接触或无覆盖时记为未归属。即使小于数值容差，唯一正面积仍可归属。分区重叠时仍分别比较各自交集。缺失、空或无效面以及重复或空 ID 会报错，空目标层可返回空映射。
