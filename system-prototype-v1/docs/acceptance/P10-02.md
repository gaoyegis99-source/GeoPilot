## 实现与接口

`geopilot.scripts.runner.run_script_snapshot(workspace_root, script_run_id, *, timeout=60.0) -> ScriptRunResult` 先核对脚本 SHA-256，以独占 `process.log` 领取一次执行。启动目录为 `workspace_root/scripts/{script_run_id}`。固定参数如下，继承本机 GIS 和系统环境，Python 的 `-E` 忽略 `PYTHON*` 环境覆盖。

```text
<sys.executable> -E -B -u -X utf8 snapshot/script.py --request snapshot/request.json
```

脚本从请求的 `asset_files` 读取暂存文件和图层，从 `parameters` 读取参数，写入本次目录的 `outputs/`。`capture_process` 返回真实退出码、标准输出和标准错误。进程超时沿用 P4 的进程组终止机制。日志保存固定命令、两路输出、退出码及定位错误。

`result.json` 原子发布，包含运行编号、草稿版本、起止时间、终态、退出码、超时标志、日志路径、错误和输出清单。`load_script_result(workspace_root, script_run_id)` 重开同编号结果。退出 `0` 后，运行器重开 `outputs/` 内的普通文件，按相对路径与字节数记录。过程失败时保留部分文件和日志，结果清单为空。正式成果和正式运行沿用原目录与记录。
