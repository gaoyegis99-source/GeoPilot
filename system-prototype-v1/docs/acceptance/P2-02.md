# P2-02 工具注册表

2026-11-11，建议状态 `REVIEW`。P2-01 与 P0-03 已验收。`ToolRegistry` 以 `(id, version)` 保存经 `ToolContract` 校验的快照，拒绝重复版本。`get` 可查指定版本或最高已登记版本，`list` 按 `(id, version)` 排序，并按运行器及可用性筛选。查询返回 `RegisteredTool(contract, available, reason)`，每份契约副本与内部快照隔离。

Python 工具的可用性根据显式传入的实现 ID 和当前 Python 的 `required_modules` 静态解析结果判断。QGIS 按显式配置、`GEOPILOT_QGIS_PROCESS`、`PATH` 的优先级定位入口，首次需要清单时在独立临时目录以 20 秒超时执行 `qgis_process --json list`。清单作为已登记 QGIS 算法的可用性依据，探测版本可通过 `qgis_version` 查询。清单和结果以注册表实例为生命周期。环境变更后，重建注册表可重新探测。工具计算能力由运行适配器验证。 [QGIS 命令行处理文档](https://docs.qgis.org/3.44/en/docs/user_manual/processing/standalone.html)

## 实际测试

实现前先运行指定测试，模块尚不存在，退出 `2`。实现后使用 P0 已验收的隔离 QGIS 入口及独立 pytest 临时目录。

```bash
p2_registry_tmp=$(mktemp -d /tmp/geopilot-p2-02.XXXXXX)
PYTEST_DEBUG_TEMPROOT="$p2_registry_tmp" PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 \
  GEOPILOT_QGIS_PROCESS="$PWD/.environments/qgis-deb/qgis_process" \
  python -m pytest tests/tools/test_registry.py -q \
    --junitxml=artifacts/test-results/p2-02-junit.xml
```

实测 `11 passed in 3.31s`，退出 `0`。另从独立临时目录执行同一个入口的 `--json list`，退出 `0`，JSON 中 `qgis_version` 为 `3.44.15-Solothurn`，`providers.native.algorithms` 包含 316 个算法，其中有 `native:buffer` 和 `native:centroids`。测试登记 `qgis-buffer` 后实际可用，明确登记的未知算法不可用，清单里的 `native:centroids` 仍未登记。

| 验证项 | 实际证据 |
|---|---|
| 版本与排序 | 精确版和最高版均可查，未知版本和 ID 抛 `KeyError`，重复版抛 `ValueError`。同 ID/version 四个并发调用仅一项登记成功。 |
| 依赖与筛选 | Python 实现未配置、模块缺失分别有原因。子模块解析未导入其父包。筛选按已登记运行器和可用性。 |
| 快照隔离 | 修改原契约、查询结果或列表中的字典及 JSON 默认值，随后查询保持原值。 |
| QGIS 错误 | 显式路径优先，入口缺失、子进程非零退出、超时、JSON 不可解析和清单格式错误均标记不可用。异常探针测试不替代真实清单验证。 |
