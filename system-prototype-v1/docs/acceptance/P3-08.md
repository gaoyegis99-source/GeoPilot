## 公共接口

`compile_plan_steps(plan, method, *, registry)` 返回规范参数的有序 `PlanStep` 元组。编译核对方法和工具的精确版本、方案问题、声明角色、固定顺序、模板和契约端口。选项绑定与字面量使用 P2-03 规范化，已存的绑定参数必须与原值或规范值逐值一致。JSON 布尔值和数值分别比较。声明的工具默认值可进入规范快照，重复编译保持相同值。输出沿用方案的 `target` 和 `layer`，同时检查运行控制文件与各输出目标的路径冲突。

`compile_step_request(plan, step_key, *, run_id, asset_files, prior_results, workdir_ref=None)` 使用已确认快照和已暂存的资产文件。前序成果须来自当前运行和对应的已成功步骤。其命名成果路径、类型和显式图层须与快照一致。快照省略图层时，使用实际报告的图层。默认工作目录引用为运行 ID，步骤日志为 `steps/<step_key>/process.log`，取消文件为 `cancel.flag`。不可编译的内容使用 `PlanCompilationError` 记录代码、字段及原因。
