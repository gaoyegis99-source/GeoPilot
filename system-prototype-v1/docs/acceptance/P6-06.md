# P6-06 面对象质心归属

Agent-B 建议 `REVIEW`，P6-01 已验收。依据 V2.0 §5.4 和 §8.5，`geopilot.gis.vector.boundary_assignment.assign_by_centroid(targets, zones, *, boundary_tie="unassigned")` 返回完整目标 `source_feature_id` 到分区 `source_feature_id` 或 `None` 的映射。两层须为有效的 Polygon 或 MultiPolygon，标识转为字符串后必须非空且唯一。共用 CRS 校验要求同一已知投影米制 CRS，非空图层的范围须在其适用区内。

使用裁剪前对象的实际质心。质心只与一个分区相交并且严格位于其内部时归属该分区。质心落在区界、孔壁、两个分区相交范围或所有分区之外时记录未归属。目标质心在目标自身之外或孔内时，仍按质心的实际位置判断。分区和目标的行索引不参与归属。
