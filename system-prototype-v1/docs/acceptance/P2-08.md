# P2-08 QGIS 步骤适配器

2026-11-11，Agent-B 建议 `REVIEW`。前置 P0-03、P2-01 至 P2-03 已验收。`geopilot.execution.qgis_runner.run_qgis` 通过共用步骤交接校验工具精确版本、路径和参数，执行注册表中可用的 QGIS 算法。

`bindings` 是应用加载的本机映射，键为 `ToolContract.implementation`。首份 [缓冲映射](../../config/runner_bindings/qgis-buffer.yaml) 包含 `native:buffer` 的输入、参数、成果名和枚举索引。所有角色必须与契约匹配，目标名不能重复，枚举需要覆盖全部声明选项。入口按 `qgis_process` 参数、`GEOPILOT_QGIS_PROCESS`、`PATH` 依次解析。

交叉审查发现 QGIS 会忽略 `DISTANCE_TYPO` 并以默认距离正常退出。适配器现在通过同一可执行入口先运行 `qgis_process --json help <algorithm>`，核对实际算法、参数名、成果角色、缺省值和枚举索引。CLI 允许的可选项及有默认值的未映射项仍可省略，枚举显示标签可随语言变化。发现失败或绑定不合规时结束在执行前检查，日志保留算法查询，计算进程尚未启动。

适配器以运行目录为工作目录执行 `qgis_process --json run <algorithm> -`，通过 stdin 传递参数 JSON。命名输入使用 GeoPackage 图层 URI，命名成果使用新 GeoPackage 的 OGR 目标 URI。QGIS 返回的路径与图层必须和预期一致，共用交接随后重开实际文件并核对成果类型。成功记录 QGIS、GDAL、PROJ 等实际版本。当前显式命名的成果图层使用 GeoPackage。距离投影适用性的执行前门禁由 P2-10 接入。 [QGIS 命令行 JSON 协议](https://docs.qgis.org/3.44/en/docs/user_manual/processing/standalone.html)
