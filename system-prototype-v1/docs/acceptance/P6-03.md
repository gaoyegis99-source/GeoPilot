# P6-03 几何内部选择

`select_within(targets, area)` 复用 P6-02 的几何校验、已知等价 CRS 校验与范围并集，再用 Shapely 的 DE-9IM `within` 对完整目标判断。目标各部分都位于范围中且两者内部相交时入选。仅在外边或孔壁接触的点、线、面不入选。从内部延伸到边界的线端点和与范围共享边界的内侧面可以入选。输出保留原始行顺序、索引、属性、几何及 CRS。[实现](../../src/geopilot/gis/vector/spatial_relations.py)
