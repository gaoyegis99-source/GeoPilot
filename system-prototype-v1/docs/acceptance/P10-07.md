## 真实结果

| 场景 | 核对结果 |
|---|---|
| 同编号的脚本试验与正式运行 | P0-05 建筑点先经成功试跑、人工校验、独立工具配置和正式方案运行，得到 `building-west`。随后同编号试验写出可读 GeoPackage 并退出 `7`。脚本 API 返回 `FAILED`、实际日志和空成果清单，下载该试验文件返回 `404`，收录返回 `SCRIPT_RUN_INVALID`。正式 API 保持 `SUCCEEDED/PASSED`，正式文件、下载字节、运行和成果记录与试验前一致。 |
| PostGIS 实际停库后复现 | 私有 Unix socket 连接读库，使用只读角色导出点。源 ID `1` 从 `(10, 30)` 改为 `(11.25, 30.75)` 后重导，生成同一逻辑资产的 v2。容器退出后真实重连失败。两次脚本试验用同一脚本 SHA-256，分别通过 v1、v2 的独立参考校验。两个精确确认方案在停库状态下均以退出码 0 完成，状态为 `SUCCEEDED/PASSED`，输出各版 EPSG:4326 坐标。SQLite 来源、脚本和正式暂存的文件组指纹均匹配所引用的资产版本，旧版快照字节保留。 |

Docker `28.1.1` 使用本机缓存镜像 `postgis/postgis:16-3.5`，镜像摘要 `sha256:94146ac37bc61e2322f88016056c5920729cb8c64c8542ed590af8fc2abdac07`。容器使用私有 socket、`--pull=never --network none` 及临时数据库目录。实际引擎 PostgreSQL `16.9`、PostGIS `3.5.2`，本机 Psycopg `3.3.4`。快照文件、暂存请求与 SQLite 检查均未发现测试连接串、口令或 socket 路径。[PostGIS 适配验收](P10-05.md) · [版本验收](P10-06.md)

## 可选特性状态

当前 PostGIS 适配 `PASS`，实跑覆盖导出、重导、停库和两版离线执行。只有已实际执行并核对结果的环境记录 `PASS`。交付未接入适配器时记录 `NOT_IMPLEMENTED`。适配器存在但缺 Psycopg、Docker 或可用本机镜像时，测试报告跳过原因，验收记录 `NOT_RUN`。

实际用空 `PATH` 启动同一 Python 解释器，脚本用例通过，PostGIS 用例报告 `An isolated local PostGIS fixture requires Docker`，得到 `1 passed, 1 skipped`。该次结果用于验证可选依赖缺失的呈现。[人工收录验收](P10-04.md)

## 实际命令

```bash
p10_ext_tmp=$(mktemp -d /tmp/geopilot-p10-07-final-XXXXXX)
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONDONTWRITEBYTECODE=1 \
  python -m pytest tests/integration/extensions -q -p no:cacheprovider \
  --basetemp "$p10_ext_tmp/pytest" --junitxml="$p10_ext_tmp/p10-07-junit.xml" -rP
p10_optional_tmp=$(mktemp -d /tmp/geopilot-p10-07-optional-XXXXXX)
mkdir "$p10_optional_tmp/bin"
p10_python=$(command -v python)
PATH="$p10_optional_tmp/bin" PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONDONTWRITEBYTECODE=1 \
  "$p10_python" -m pytest tests/integration/extensions -q -rs -p no:cacheprovider \
  --basetemp "$p10_optional_tmp/pytest" --junitxml="$p10_optional_tmp/optional-junit.xml"
```

最终完整运行 `2 passed, 1 warning in 9.53s`，退出 `0`，JUnit 为 2 项、零失败、零错误、零跳过。缺 Docker 运行 `1 passed, 1 skipped, 1 warning in 3.30s`，退出 `0`。警告来自 Starlette 测试客户端对 AnyIO 类型别名的弃用提示。
