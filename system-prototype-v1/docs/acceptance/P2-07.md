# P2-07 局部投影选择与转换

- 日期：2026-11-11（Asia/Shanghai）
- 实施：GIS 投影 Agent
- 建议状态：`REVIEW`
- 前置：P2-04、P2-05、P2-06 已由主控验收

`select_measurement_crs(metadata, method=..., target_crs=...)` 从真实源 CRS 和范围开始检查。局部距离的默认目标是 PROJ 库中唯一覆盖整个 WGS 84 范围的 UTM 区。面积默认评估 EPSG:6933。显式目标走相同的投影米制、目标范围和测量策略门禁。目标范围由输入边界的实际转换获得，缺少覆盖证据或目标为 Web Mercator 时停止。已知的 EPSG:3857 可以作为重投影来源。

`reproject_vector(...)` 实际打开本机矢量，按已验证的目标转换几何。转换后再检查实际几何范围，暂存为 GeoPackage 并重新打开，核对 CRS、几何及属性值。发布前复核源文件组指纹和状态，用同文件系统的原子硬链接创建新输出。函数返回 `ReprojectionResult(path, layer, decision)`，默认层名为 `projected`。
