## 接口与文件交接

`PostGISSource` 保存本机连接别名、schema、表或视图、几何列、可选有序属性列及筛选。筛选为按字段联合的等值或 `null` 条件。Psycopg 分别引用 SQL 标识符和绑定筛选值，元数据与要素在同一 `REPEATABLE READ READ ONLY` 事务读取。连接串只作为调用时的本机参数。连接和读库错误使用固定的结构化消息，原始驱动错误从异常链展示中省略。[Psycopg 标识符与参数](https://www.psycopg.org/psycopg3/docs/api/sql.html) · [PostgreSQL 事务语义](https://www.postgresql.org/docs/16/sql-set-transaction.html)

`export_postgis_snapshot(destination, *, conninfo, source, layer="snapshot")` 返回含 `path`、`layer`、`origin` 和 `fingerprint` 的 `PostGISSnapshot`。适配器读取实际 EWKB 和 SRID，按源库 `spatial_ref_sys` 解析 CRS，筛选为空时使用几何列的声明。输出先在独立临时路径生成，复核命名图层、要素数、实际几何及 CRS 后发布。连接别名、表、几何列、字段、筛选、事务 UTC 时间与 SRID 写入同一文件的层级 `gpkg_metadata`，可用 `read_postgis_snapshot_origin(path)` 重开。[EWKB 与 SRID](https://postgis.net/docs/ST_AsEWKB.html) · [GDAL GeoPackage 元数据](https://gdal.org/en/stable/drivers/vector/gpkg.html#metadata)

`import_postgis_snapshot(database_path, destination, *, conninfo, source, layer="snapshot")` 登记逻辑选择的首个版本。既有 SQLite 字段保存 `postgis_snapshot`、本机 `FileSource`、P1 内容指纹和元数据。登记在写事务内复核文件状态，重复选择或 SQLite 写入失败时清理本次候选文件。已登记的资产可用原版本引用和 P1 解析、暂存接口读取。P10-06 使用 `PostGISSource.source_key` 和独立导出入口管理后续版本。[适配器](../../src/geopilot/data/postgis_import.py)

## 实际验证

宿主以缓存镜像 `postgis/postgis:16-3.5` 运行 PostgreSQL 16.9 和 PostGIS 3.5.2，镜像摘要为 `sha256:94146ac37bc61e2322f88016056c5920729cb8c64c8542ed590af8fc2abdac07`。测试容器使用 `--pull=never --network none`、临时数据库文件系统及私有 Unix socket，无映射端口。测试角色仅有样本查询权限。宿主使用 Psycopg 3.3.4、Pyogrio 0.12.1、GDAL 3.11.4；导出完成后停止并清理容器。

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONDONTWRITEBYTECODE=1 \
  python -m pytest tests/data_adapters/test_postgis_snapshot.py -q -p no:cacheprovider
p10_pg_tmp=$(mktemp -d /tmp/geopilot-p10-05-final.XXXXXX)
PYTEST_DEBUG_TEMPROOT="$p10_pg_tmp" PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 PYTHONDONTWRITEBYTECODE=1 \
  python -m pytest tests/data_adapters/test_postgis_snapshot.py -q -p no:cacheprovider \
  --junitxml=artifacts/test-results/p10-05-junit.xml

  --ignore=tests/data_adapters/test_postgis_snapshot.py -q -p no:cacheprovider
```

先行测试因缺少适配器收集退出 `2`。初次真实导出在重开时发现 GDAL 为数据集元数据生成 PAM 旁车，改为原生层级元数据后单文件复核通过。最终专项 `5 passed, 1 warning in 7.81s`，退出 `0`，警告为缺失 CRS 样本的预期 GDAL 提示。关联回归 `99 passed in 5.04s`，退出 `0`。[专项 JUnit](../../artifacts/test-results/p10-05-junit.xml)

- 真实选择 `"Survey 2024"."Plot records"`，带空格的字段、带单引号的值、布尔和空值联合筛选命中 ID 1、2。重开 `selected` 层得到两个 EPSG:4326 点 `(10, 30)` 和 `(12, 31)`，原视图字段实测 `transaction_read_only=on` 和 `transaction_isolation=repeatable read`。GeoPackage 只读校验为 `ok`，含空值的整数列保留 `9007199254740993`。导出 UTC 时间为 `2026-11-11T13:30:16.011926+00:00`，P1 内容指纹为 `74fcb6a0c9630599833da5b925e57935bd639fd0d21ebd124da2408d1114f084`，与原实跑路径的 SQLite 登记一致。[正式快照](../../artifacts/smoke/postgis-snapshot/run.85p3e1px/filtered.gpkg) · [登记记录](../../artifacts/smoke/postgis-snapshot/run.85p3e1px/catalog.sqlite)
- 容器停止后，通过 `resolve_asset` 和真实运行暂存重开同一版本及指纹。本地拓扑查询在给定经纬度范围内精确命中 ID 1。错误连接与错误筛选均无快照，实际异常输出、GeoPackage 和 SQLite 检查未检出测试凭据或 socket 路径。
- 空选择保留实际声明的 Point 类型和 EPSG:4326。无 CRS 样本按 P1 记录 `CRS_UNKNOWN`。同一选择同时返回 4326 和 3857 时拒绝发布，单选实际 3857 行得到命名投影图层。现有目标文件及其内容保留，实写触发器拒绝登记后，候选 GeoPackage 和资产行均未发布。[空结果](../../artifacts/smoke/postgis-snapshot/run.85p3e1px/empty.gpkg) · [未知 CRS](../../artifacts/smoke/postgis-snapshot/run.85p3e1px/unknown.gpkg) · [EPSG:3857 实证](../../artifacts/smoke/postgis-snapshot/run.85p3e1px/projected.gpkg)
