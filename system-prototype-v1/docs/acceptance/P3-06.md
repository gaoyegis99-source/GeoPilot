## 公共接口

`geopilot.plans.models` 提供 `AnalysisPlan`、`PlanStatus`、`PlanStep`、`PlanOutput`、`PlanIssue`。方案保存 `TaskGoal` 和精确的 `DataAssetRef`、`MethodRef`、`ToolRef`。步骤、成果、规则和问题均显式声明，并保持输入顺序。步骤输入复用资产角色和命名输出引用，关键选项及已解析参数保存有限的 JSON 值。

草稿可记录未填项、`tool: null` 的步骤及带字段位置的问题。确认态要求非空步骤、每步绑定精确工具版本且问题列表为空。成果目标复用 `StepFileRef` 的路径与图层约束，`target` 为运行目录内的相对路径，`layer` 可省略。Pydantic 模型执行状态约束和路径检查，生成的 JSON Schema 描述快照字段与类型。

从原型根目录生成并验证 [方案 JSON Schema](../../artifacts/schemas/analysis-plan.schema.json)。

```bash
PYTHONPATH=src python - <<'PY'
import json
import re
from pathlib import Path

import yaml
from jsonschema import Draft202012Validator

from geopilot.plans.models import AnalysisPlan

schema = AnalysisPlan.model_json_schema()
Draft202012Validator.check_schema(schema)
Path("artifacts/schemas/analysis-plan.schema.json").write_text(
    json.dumps(schema, indent=2, ensure_ascii=False) + "\n", encoding="utf-8"
)
validator = Draft202012Validator(schema)

source = Path("../docs/source/GeoPilot_产品需求规格与系统详细设计报告_V2.0.md")
section = source.read_text(encoding="utf-8").split("## 8.3 AnalysisPlan 接口", 1)[1]
section = section.split("## 8.4 ToolContract 接口", 1)[0]
header, buffer_step, outputs = (
    yaml.safe_load(block) for block in re.findall(r"```yaml\n(.*?)```", section, flags=re.S)
)
draft = {**header, "steps": [buffer_step], **outputs}
prepare = {
    "key": "choose_measurement_method",
    "tool": {"id": "prepare-roads", "version": 2},
    "inputs": {"source": {"asset": "roads"}},
    "parameters": {"method": "local_projected", "crs_ref": "local_crs_001"},
    "outputs": {"roads": {"type": "vector_line", "target": "intermediate/roads.gpkg", "layer": "roads"}},
}
confirmed = {
    **draft, "status": "confirmed", "steps": [prepare, buffer_step],
    "expected_artifacts": outputs["expected_artifacts"][:1],
}
for data in (draft, confirmed):
    validator.validate(data)
    plan = AnalysisPlan.model_validate(data)
    validator.validate(plan.model_dump(mode="json"))
    assert AnalysisPlan.model_validate_json(plan.model_dump_json()) == plan
    assert [step.key for step in plan.steps] == [step["key"] for step in data["steps"]]
    assert [step.tool.version for step in plan.steps] == [step["tool"]["version"] for step in data["steps"]]
    assert plan.steps[-1].parameters == buffer_step["parameters"]
    assert list(plan.inputs) == list(header["inputs"])
    assert list(plan.check_rules) == outputs["check_rules"]
    print(f"{plan.id} v{plan.version} {plan.status.value}  PASS")
PY
```
