## 实现与接口

`geopilot.scripts.models` 提供 `ScriptDraft` 和 `ScriptSnapshot`。草稿保存脚本 ID、正整数版本、UTF-8 文本、精确 `DataAssetRef`、JSON 参数和创建时间。快照保存原草稿版本、独立运行编号、脚本相对路径与 SHA-256、输入资产引用、暂存文件路径及图层、参数和创建时间。加载时核对路径身份和脚本 SHA-256。

| `geopilot.scripts.snapshot` 入口 | 行为 |
|---|---|
| `save_script_draft(workspace_root, script_id, *, script_text, inputs, parameters)` | 在 `scripts/drafts/{script_id}/{version}.json` 追加草稿。并发申请通过同目录硬链接的独占发布分配不同版本。 |
| `load_script_draft(workspace_root, script_id, version)` | 读取确切版本。 |
| `create_script_snapshot(database_path, workspace_root, script_id, version, *, script_run_id=None)` | 独占创建 `scripts/{script_run_id}`，复用已登记资产的重开和暂存。准备完成后原子发布快照目录。 |
| `load_script_snapshot(workspace_root, script_run_id)` | 重开已经发布的快照。 |

脚本和请求分别是 `snapshot/script.py` 与 `snapshot/request.json`。快照目录权限为 `0500`，两个文件均为 `0400`。运行根权限为 `0700`，拥有独立 `inputs/` 和 `outputs/`。根目录可供后续进程锁和日志使用。脚本和 JSON 请求发布之前就已设置只读权限。准备失败时清理本次运行候选目录。脚本区复用 SQLite 资产引用和实际文件组，正式运行和成果沿用既有目录及记录。
