# P5-08 MapLibre 矢量预览

Agent-B 建议 `REVIEW`。P5-01 与 P4-11 已验收。按 V2.0 §12.3.6，地图从本机预览 API 读取已选资产版本及已登记成果，结果拾取回传原成果 ID。[设计报告](../../../docs/source/GeoPilot_产品需求规格与系统详细设计报告_V2.0.md) · [原子任务](../../plans/04_TASKS/P5/P5-08.md)

`MapPanel` 接收 `layers`、`focusLayerId`、可选 `focusRevision` 和 `onArtifactSelect`。每个图层有 `id`、`name`、`previewUrl`、`kind`。资产 URL 含精确版本，成果 URL 使用实际 ID。面、线、点在 MapLibre 中用同一 GeoJSON 来源的不同样式层绘制。首次加载及定位采用可绘制范围；重复定位可通过递增 `focusRevision` 恢复已隐藏图层。地图拾取只返回实际成果 ID。[MapPanel](../../frontend/src/features/map/MapPanel.tsx) · [MapLibre 图层与拾取 API](https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/)

地图底色、样式和 worker 随本机前端发布。每个图层独立请求、撤销旧请求并处理失败。共享错误组件显示地图预览阶段、错误代码、字段和可展开详情；重试只作用于当前图层。预览和下载、日志使用独立的本机引用。[MapLibre 6.17.0](https://github.com/maplibre/maplibre-gl-js/releases/tag/v6.17.0)
