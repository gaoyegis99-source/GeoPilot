# P7-02 分析区邻域外扩计算

## 接口

`expand_analysis_window(grid, bounds, radius_pixels) -> ExpandedWindow` 使用 `RasterMetadata` 中的宽、高和仿射。`bounds` 按西、南、东、北顺序，坐标由调用方转换或确认在栅格 CRS 下。`radius_pixels` 是非负整数，适用于分析窗的四侧。

结果提供 `requested_bounds`、`analysis_window`、`analysis_bounds`、`expanded_window` 和 `expanded_bounds`。分析窗按网格边界向外覆盖整个请求范围。外扩以算法半径增加像元，坐标距离分别由网格横纵尺度决定。源覆盖不足会产生 `ValueError`，保留所需邻域的完整性。

窗口由真实像元边界的二分查找确定，支持十进制边界精确对齐及极小跨界重叠。网格须为轴对齐的北向上仿射。旋转、倾斜和反向轴在生成邻域前明确报错。该入口检查几何覆盖，裁取和计算步骤负责读取实际像元及掩膜。

新增 [extent_expansion.py](../../src/geopilot/gis/raster/extent_expansion.py)、[test_extent_expansion.py](../../tests/gis/raster/test_extent_expansion.py) 和本验收报告。

## 实测

- P0 DEM 的分析窗 `Window(2, 2, 3, 3)` 对应 `(500020, 4400020, 500050, 4400050)`。半径 1 得到 `Window(1, 1, 5, 5)`，外扩范围 `(500010, 4400010, 500060, 4400060)`。实际重读外扩窗得到 25 个有效像元，仿射左上角为 `(500010, 4400060)`。[P0 样本](../../tests/fixtures/raster/README.md)
- 实建 `6 m × 14 m` 像元的 GeoTIFF。分数像元范围向外对齐后得到 `3 × 4` 分析窗。半径 2 在横纵方向的每侧分别增加 `12 m`、`28 m`，得到 `7 × 8` 外扩窗。Rasterio 重开核对两窗坐标范围。
- 实测十进制边缘、相邻浮点数产生的跨边界重叠和半径零。四条源边的邻域不足、原分析范围越界、无效半径和不支持的仿射均产生明确错误。
