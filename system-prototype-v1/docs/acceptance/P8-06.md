# P8-06 原网格 NDVI

2026-11-12 主控签收，主控联合 194 项通过。执行角色 Agent-B。[主控 JUnit](../../artifacts/test-results/p8-06-root-junit.xml)`write_ndvi(reflectance, quality_mask, destination)` 比较两输入的已知 CRS、宽高和六项仿射参数。逐个 256 × 256 像元块取质量值 `1`、原 GDAL 有效掩膜和两个有限反射率的交集，计算 `(nir − red) / (nir + red)`。Float64 分母严格为零或算术结果无法用有限数表示时写入 NaN。结果为原网格单带 Float64 `ndvi`，单位 `1`，NaN 为 NoData。[实现](../../src/geopilot/remote_sensing/indices.py) · [USGS NDVI 定义](https://www.usgs.gov/landsat-missions/landsat-normalized-difference-vegetation-index)

`NdviResult(metadata, summary)` 返回重开后的元数据及统计。`GEOPILOT_NDVI` 域中的 `SUMMARY` JSON 保存同一摘要。总像元依次计入质量无效、反射率无效、零分母、算术无效或有限结果。有限结果计数和有效比例包含越界值，另外记录越界数量、极值和行优先首个越界像元的零基行列及原值。越界值保留供成果规则核对，P8-07 从时相变化样本排除这些像元。

- Sentinel-2 PB05.11 标准结构合成 XML 和原 DN 经过真实定标、QA 写入与 NDVI 写入。DN `800/1200` 得到 `−0.02/+0.02`，分母在 Float64 严格为零。重开 3 × 4 的成果有 4 个质量无效、2 个零分母和 6 个有限值。有限值为约 `5`、`−5`、`1`、`−1`、`0.5`、`−0.5`，行 `0`、列 `1` 为首个越界。原始数据与两个中间成果指纹一致。 [Copernicus Sentinel-2 产品说明](https://sentiwiki.copernicus.eu/web/s2-products)
- Landsat Collection 2 的同链路重开值为 `11/15`、`0` 和 `−11/15`，绝对误差小于 `1e-15`。QA 云位、近红外饱和、光谱填充值与原 GDAL 掩膜传播到预期像元。有效 NDVI `0` 保留。
- 独立探针读取原始 Sentinel-2A PB05.11 XML，并以 6 个合成像元串接真实三个阶段。重开值为 `[[NaN, 5.000000000000001, 1.0], [0.49999999999999994, -1.0, NaN]]`，质量无效 1，零分母 1，有限值 4，越界 1。[原始产品 XML](https://sentinel-s2-l2a.s3.amazonaws.com/products/2024/8/31/S2A_MSIL2A_20240831T103021_N0511_R108_T32UMA_20240831T151747/metadata.xml)
- 259 × 261 栅格跨四块重开一致，首个全格越界位于行 `12`、列 `258`。另验证单带掩膜、NaN、Inf、浮点中间溢出、接近零的可表示非零分母、全无效和错半像元等情况。最后一块的非法质量码阻断正式文件发布，已有目标伴随文件保留。
