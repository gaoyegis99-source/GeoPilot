`geopilot.domain.tool_contract` 提供 `ToolRef`、`ToolContract`、`ParameterSpec` 和 `MeasurementPolicy`。工具的十个契约字段必须显式提供，版本为严格正整数。支持 `qgis` 和 `python` 运行器、命名输入输出、显式参数映射及有序前提和检查规则。模型拒绝未声明字段。

参数声明检查类型、有限数、边界、数值单位、唯一枚举和默认值。`ParameterSpec.validate_value(value)` 与默认值共用同一校验，对已经处于契约单位的输入返回成功或抛出 `ValueError`。平面距离与面积策略必须保持两项 CRS 保护标志开启。模型校验策略声明，实际输入 CRS 检查、参数换算和工具调用在后续任务验证。

[QGIS 缓冲契约 YAML](../../config/tools/qgis-buffer.yaml) 按 V2.0 §8.4 声明 `qgis-buffer` v1、`native:buffer`、源线图层、缓冲面输出、六项参数和局部投影距离策略。
