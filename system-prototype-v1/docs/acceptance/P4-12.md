## 接口与实现

`geopilot.checks.input_checks.check_step_inputs(step, required_coverage=...)` 重开已准备步骤的实际空间输入，返回有序 `InputCheckResult`。记录包括规则名、`input` 阶段、字段、`blocking` 或 `warning` 严重程度、判定、观察值、期望条件和消息。`require_input_checks` 汇总证据，有阻断失败时抛出携带全部结果及阻断项的 `InputCheckError`。

输入检查复用实际 GeoPackage、矢量和 GeoTIFF 读取器及 P2 测量策略。检查声明所需的 CRS、水平单位、适用区、范围、图层类型、几何、字段和角色间 CRS 一致性。属性筛选按所选字段检查，按契约需求决定是否检查 CRS。可选 `CoverageRequirement(bounds, crs)` 使用同 CRS 的实际栅格网格足迹或面几何并集核对完整覆盖。

`run_step(..., input_preflight=preflight_step_inputs)` 在派发计算前把每条规则保存为 `input_check` 日志。阻断失败通过现有步骤信封记录 `preflight` 错误，`exit_code` 为空。未传钩子的调用沿用已验收入口。

## 实际验证

```bash
p4_input_tmp=$(mktemp -d /tmp/geopilot-p4-12.XXXXXX)
PYTEST_DEBUG_TEMPROOT="$p4_input_tmp" PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 \
  GEOPILOT_QGIS_PROCESS="$PWD/.environments/qgis-deb/qgis_process" \
  python -m pytest tests/checks/test_input_checks.py -q \
  --junitxml=artifacts/test-results/p4-12-junit.xml
```

| 检查 | 原始结果 |
|---|---|

| 实现后运行专项 | `18 passed in 6.43s`，退出 `0`，无跳过。 |
| P2 CRS、距离、面积、投影和现有实际运行入口回归 | `65 passed in 19.77s`，退出 `0`。包含原有测量固定用例、属性筛选和裁回工具测试。 |
