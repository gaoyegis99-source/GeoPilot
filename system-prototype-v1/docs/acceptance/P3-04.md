# P3-04 步骤依赖拓扑校验

2026-11-11（Asia/Shanghai），Agent-F 提交 `REVIEW`。依据 V2.0 §4.2、§8.5、[P3-04 原子任务](../../plans/04_TASKS/P3/P3-04.md)和[公共契约](../../plans/01_ARCHITECTURE/02_PUBLIC_CONTRACTS.md)。

`validate_dependencies(input_roles, steps)` 接收声明的资产角色和有序步骤。方法的 `MethodStep` 与方案的 `PlanStep` 共用输入绑定，校验器只读取 `key`、`inputs` 和 `outputs`，返回 `tuple[DependencyIssue, ...]`。字段路径使用步骤声明的零基索引，问题包含代码、字段和原因。步骤顺序与原始配置保持一致。

| 问题 | 代码与字段定位 |
|---|---|
| 重复步骤键 | `DUPLICATE_STEP_KEY`，重复声明的 `steps.<index>.key` |
| 资产角色未声明 | `UNKNOWN_ASSET_ROLE`，`steps.<index>.inputs.<port>.asset` |
| 步骤或输出未声明 | `UNKNOWN_STEP` 或 `UNKNOWN_OUTPUT`，输入绑定的 `step` 或 `output` 字段 |
| 自引用或未来引用 | `SELF_STEP_REFERENCE` 或 `FUTURE_STEP_REFERENCE`，输入绑定的 `step` 字段 |
| 多步骤循环 | `DEPENDENCY_CYCLE`，指向实际闭环中的一个输入绑定，消息保存闭环路径 |

声明检查按原顺序收集问题。标准库 `graphlib` 对可解析的依赖边检查循环，额外记录一个闭环路径。未知输出和重复步骤键产生各自的问题，相关歧义引用排除在图外。配置能否执行还需后续工具、参数、顺序和确认规则校验。
