`register_asset(database_path, path, *, layer=None)` 使用已初始化的 SQLite。它按规范化绝对路径选择本机矢量、GeoPackage 或 GeoTIFF/COG 读取器，登记实际选定的图层。来源类型、路径和图层组成唯一来源键。同路径不同 GeoPackage 图层独立登记。仓库以 Pydantic JSON 保存元数据和本机引用，创建时间为 UTC。

登记先采样主文件及已知旁车状态并计算内容指纹。读取元数据后再次计算指纹和采样状态，两次内容和状态一致才能继续。`BEGIN IMMEDIATE` 后再次核对状态，在同一写事务内查询已有版本并提交。首次登记建立 v1，内容一致时返回原记录。已变内容目前返回 `INPUT_CHANGED`，P1-08 将处理历史版本追加。缺失 CRS 的可读空间源仍保存为可用，元数据带 `CRS_UNKNOWN`。读取失败或检测到源变化时，事务不产生新记录。

`capture_file_state` 复用指纹模块的文件组采样，比较角色、路径、设备、inode、大小、mtime 与 ctime。该状态仅用于当前操作的前后比较，内容 SHA-256 用于持久化，已有两种指纹策略不变。
