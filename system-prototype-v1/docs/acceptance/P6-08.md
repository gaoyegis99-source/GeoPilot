# P6-08 原始对象去重与跨区统计

2026-11-11（Asia/Shanghai），Agent-F 提交 `REVIEW`。依据 V2.0 §5.4、§8.5、§11.3 和 §12.3.7。[P6-08 任务](../../plans/04_TASKS/P6/P6-08.md)

`polygon-zone-statistics` v1 锁定完整对象关系判断、裁回分析范围和分区统计。统计接收裁后 `targets`、裁前 `original_targets` 和 `zones`，显式保存 `boundary_assignment`、`boundary_tie`、`area_crs` 及 `square_meter`。用 `source_feature_id` 对裁后的面片求并集，同一 ID 的重叠与重复面片只贡献一次面积。重复完整原面须拓扑一致，每个裁后 ID 须能找到原面。纯边界接触保留一个零面积未归属对象。[方法](../../config/methods/polygon-zone-statistics.v1.yaml) · [工具契约](../../config/tools/python-polygon-zone-statistics.yaml) · [统计实现](../../src/geopilot/gis/vector/polygon_statistics.py) · [Python worker](../../src/geopilot/gis/tools/polygon_zone_statistics.py)

面积拆分分摊裁后等积面积，任一区存在正贡献即将该 ID 在全局已归属中计一次。未覆盖的剩余面积写入空分区明细。质心和最大重叠使用完整原面选择单一分区或未归属，整份裁后等积面积进入该分配结果。CSV 包含 `source_feature_id`、`zone_id`、`object_status` 和 `area_m2`。`object_status` 对同一个 ID 的所有明细一致。JSON 的 `counts` 是全局唯一 ID 数，各区 `distinct_count` 是该区收到贡献的唯一 ID 数。`areas_m2.uncovered` 表示裁后面位于分区并集以外的面积，`areas_m2.unassigned` 表示按所选规则未分配到分区的面积。
