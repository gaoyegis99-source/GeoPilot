## 本机 HTTP 与后台运行

从 `system-prototype-v1` 启动本机服务。目录和端口用于独立联调，CLI 绑定 `127.0.0.1`，读取本地版本化工具和方法配置。[服务入口](../../src/geopilot/api/server.py) · [接口契约](../../plans/01_ARCHITECTURE/02_PUBLIC_CONTRACTS.md)

```bash
p4_loopback_dir=$(mktemp -d /tmp/geopilot-p4-loopback-XXXXXX)
PYTHONPATH="$PWD/src" PYTHONDONTWRITEBYTECODE=1 python -m geopilot.api.server \
  --database "$p4_loopback_dir/project.sqlite" --workspace "$p4_loopback_dir/workspace" \
  --qgis-process "$PWD/.environments/qgis-deb/qgis_process" --port 45967
```

本次实际联调用独立 SQLite 准备内置 `attribute-filter-export@1` 草稿，登记真实 GeoPackage 的 `targets` 图层，筛选 `source_feature_id = building-west`。CLI 独立进程在 `127.0.0.1:45967` 接收真实 HTTP。只读数据库确认运行引用精确方案版本 1；成果和检查查询对应同一运行编号。

| 请求 | 实测 HTTP | 观察 |
|---|---:|---|
| `GET /openapi.json` | 200 | 本机 API 可读。 |
| 草稿 `POST /api/plans/{id}/runs` | 409 | `PLAN_NOT_CONFIRMED`。 |
| `POST /api/plans/{id}/confirm` | 200 | 版本 1 确认，运行表仍为 0，运行目录尚未生成。 |
| `POST /api/plans/{id}/runs` | 202 | 返回运行编号，由后台领取。 |
| `GET /api/runs/{id}` | 200 | 轮询同一编号得到 `SUCCEEDED / PASSED`。 |
| `GET /api/runs/{id}/artifacts` 与 `GET /api/runs/{id}/checks` | 200 | 一个可读正式成果，报告编号和状态查询一致。实际 QGIS `native:extractbyattribute` 退出 0，重开的命名图层仅含 `building-west`。 |

已存接口回归还覆盖请求类型错误 422、未知记录 404、存储错误 500、活动运行重复受理及实际后台 Python GIS。成果查询保留来源版本和可读性，运行错误随状态及诊断字段返回。[本机应用 JUnit](../../artifacts/test-results/p4-local-app-junit.xml) · [受理和查询 JUnit](../../artifacts/test-results/p4-run-api-junit.xml) · [后台联调 JUnit](../../artifacts/test-results/p4-runtime-junit.xml)

## 失败、取消与重启

- 实际三步链首步生成三条道路。第二步的启动失败、非零退出 7、超时、无效清单、输出缺失及损坏分别保存运行和步骤错误，第三步保持 `NOT_STARTED`。已生成文件和日志作为可追查的诊断；成果登记失败的真实两步运行也验证了批次回滚与零正式登记。[失败停止](P4-09.md) · [登记回滚](P4-11.md)
- 排队取消立即禁止领取，步间取消保留前一步产物，运行中取消先记录意图，再确认实际 GIS 子进程终止和退出码后发布 `CANCELLED / NOT_CHECKED`。超时另以 `PROCESS_TIMEOUT` 记录。实际进程组测试覆盖忽略 SIGTERM 的组长及关闭日志的静默后代，验证信号升级后都停止执行。[取消](P4-07.md) · [超时](P4-08.md)
- 终止执行器所在的独立进程后，旧 GIS 子进程仍持运行目录锁时启动恢复拒绝。确认旧子进程停止后，同一运行编号恢复为 `FAILED / NOT_CHECKED`，错误为 `RUN_INTERRUPTED`。实际活动步骤和请求、日志随步骤失败保留，后续待执行步骤仍未启动。另一真实崩溃样本清理未提交的成果清单，已存在输出可从诊断重新打开。[恢复回归 JUnit](../../artifacts/test-results/p4-recovery-artifact-checks-junit.xml) · [真实崩溃测试](../../tests/scheduler/test_restart_recovery.py)
