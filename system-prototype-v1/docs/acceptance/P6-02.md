# P6-02 几何相交选择

2026-11-11（Asia/Shanghai），Agent-F 提交 `REVIEW`。依据 V2.0 §5.4、§11.3 和 P6-01 手算样本。[P6-02 任务](../../plans/04_TASKS/P6/P6-02.md) · [T13 样本](../../tests/fixtures/vector/t13/README.md)

`select_intersecting(targets, area)` 校验两个 GeoDataFrame 的已知等价 CRS，按已给坐标将范围内有效 Polygon 与 MultiPolygon 作并集，以二维 `intersects` 判断每个完整目标。仅接触外框、角点或孔壁的对象也入选。返回原目标行的副本，保留顺序、索引、属性、几何和 CRS。空目标层返回同结构空结果。[实现](../../src/geopilot/gis/vector/spatial_relations.py)

范围须含至少一个有效面。任一输入图层缺少活动几何列或任一要素几何缺失、为空或无效时，函数抛出 `ValueError`。要素错误包含输入角色、行位置、索引及可用的 `source_feature_id`。CRS 缺失、未定义或不等价时，错误标明相应 CRS 字段。
