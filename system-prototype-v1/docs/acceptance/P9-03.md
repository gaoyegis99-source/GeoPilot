# P9-03 外发请求数据边界

Agent-F 实施，建议 `REVIEW`。`check_outbound_request(serialized, *, protected_literals=())` 校验实际 `ModelRequest.model_dump_json()` 的字符串或 UTF-8 字节，覆盖完整请求包装、任务摘要、候选方法和工具。违反边界时抛出 `DataBoundaryError`，例如 `OUTBOUND_DATA_REJECTED $.payload.context.goal`。未知键定位到所属的已知结构，格式错误定位到 `$`。[原子任务](../../plans/04_TASKS/P9/P9-03.md) · [校验器](../../src/geopilot/llm/data_boundary.py)

结构校验约束摘要类型、非负统计、正分辨率、准确版本以及候选选项的已声明约束。候选标识、枚举和引用条件沿用实际构建器的技术标识格式。重复键、非法 UTF-8、非有限数及额外结构均拒绝。文本检查处理 JSON 解码、Unicode 规范化及常见转义形式，并阻断路径、连接信息、WKT、坐标、原始记录及调用方传入的已知本机值。自由文本识别范围由这些模式和已知值决定。调用方提供已知样本、来源、资产编号与指纹作为 `protected_literals`。[摘要验收](P9-02.md)
