`geopilot.persistence.schema.initialize_database(path)` 在 `BEGIN IMMEDIATE` 后读取 `PRAGMA user_version`，依序应用缺失迁移并在同一事务提交 schema 和版本。重复初始化保留数据。未知高版本直接拒绝，创建表冲突会回滚本次已执行的 DDL 并保留旧表。`open_database(path)` 返回启用外键、使用 `sqlite3.Row` 的连接上下文，退出时关闭连接，业务事务由调用方提交或回滚。

v1 包含 `data_asset`、`task`、`analysis_plan` 和 `run`。数据库约束校验正整数版本、资产复合键、来源版本唯一性、任务与精确方案版本引用、方案状态及两套运行状态。可空的上下文和错误字段支持 SQL `NULL`。JSON 列与工作目录只接受文本，空间数据继续使用外部文件引用。资产来源类型与可用性在 P1-02 公共模型中校验。
