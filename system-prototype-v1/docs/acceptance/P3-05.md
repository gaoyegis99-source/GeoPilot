# P3-05 固定步骤顺序校验

2026-11-11（Asia/Shanghai），Agent-F 提交 `REVIEW`。依据 V2.0 §7.4、§8.5、[P3-05 原子任务](../../plans/04_TASKS/P3/P3-05.md)和[公共契约](../../plans/01_ARCHITECTURE/02_PUBLIC_CONTRACTS.md)。

`geopilot.plans.step_compiler.validate_step_order(method, steps)` 接收已登记方法和调用方提交的有序步骤，支持 `MethodStep` 与 `PlanStep`。`locked_order=true` 时，逐项比较方法和候选的步骤键与长度。首次不同返回 `LOCKED_STEP_ORDER`，字段为 `steps.<index>.key`，消息含预期和实际步骤。末尾缺失或额外步骤的位置也以同样规则定位。

锁定和未锁定方法都调用 P3-04 校验资产角色与前序命名输出。未锁定方法可以使用符合依赖的其他顺序。检查保留收到的原序列；顺序错误与独立的依赖错误均可返回。
