# P3-07 方案草稿生成器

Agent-C 建议 `REVIEW`。P3-02、P3-06 与任务上下文前置已验收。P3-04 验收后接入共用依赖校验。

`geopilot.plans.draft_builder.build_draft(context, method, *, plan_id, version=1, options=None)` 返回 `AnalysisPlan` 草稿。上下文须匹配方法精确版本。草稿保留已选资产引用、模板步骤顺序、工具版本、输入连接和检查规则。缺少或暂不可用的输入、无效选项、未绑定工具或成果、依赖错误和不支持的输出格式进入带字段位置的 `issues`。

选项取自用户输入与已声明的默认值。步骤参数按声明的选项引用或字面量填写。参考选项值为非空标识符，在无条件、已接受的选项值精确命中 `required_for` 或某步实际绑定该选项时必填。无效的显式选择保留其问题记录。数值选项在草稿中按方法的 `ParameterSpec` 校验，工具参数的单位换算在编译时处理。

输出目标为 `intermediate/<步骤名>/<输出端口名>.<扩展名>`。常用 ASCII 标识保留。其他名称和 GeoPackage 保留前缀使用 `encoded_` 加名称的 SHA-256 十六进制摘要，以保持路径安全且可复现。矢量写为 `.gpkg`，图层名用同一端口标识。栅格、表格和 JSON 分别使用 `.tif`、`.csv` 和 `.json`。编译器可直接读取 `PlanOutput.target` 与 `layer`。
