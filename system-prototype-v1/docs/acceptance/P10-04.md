## 接口与证据

`validate_manual_registration(database_path, workspace_root, candidate, *, registered_rules)` 是只读校验入口。它在候选专用工具注册器中检查精确版本、端口、规则、前提声明与步骤依赖。运行证据包括脚本 SHA-256、精确运行与脚本版本、退出码 0、实际日志、历史登记输入和暂存指纹、参数以及输出清单。校验器按参考重开实际输出，对照 CRS、精确 ID 与 WKT，或对照独立参考文件组指纹。返回 `RegistrationEvidence` 含脚本及候选定义版本与输出指纹。[数据模型](../../src/geopilot/scripts/registration/models.py) · [校验器](../../src/geopilot/scripts/registration/validation.py)

候选方法可多次使用同一拟收录工具。一个试验参考核对一次工具调用的结果，实际方法链可通过独立正式样例继续验证。矢量比较使用规范化几何和精确坐标，文件指纹适用于可按字节核对的输出。P10 试验清单保存文件大小，校验时的结果以当前重开文件和独立参考为依据。

先写测试，生产模块缺失时实际 `ModuleNotFoundError`，退出 `2`。最终专项 `12 passed in 8.99s`，脚本、契约与 Python 执行关联回归 `152 passed in 15.54s`，均退出 `0`。[专项 JUnit](../../artifacts/test-results/p10-04-junit.xml)

真实本地脚本进程从暂存 GeoPackage 筛得 `building-west`，退出 0。重开的图层为 EPSG:32650，点坐标精确为 `(500750, 4401500)`。移除原输入副本后，校验仍通过已登记版本与暂存指纹。试验库正式运行、成果记录均为零，核对前后试验文件内容及修改时间一致。测试随后在独立数据库与注册器手工配置同一脚本，构造、保存和确认候选方法方案，正式 Python 进程退出 0，运行 `SUCCEEDED/PASSED` 并重开同一参考点。

另用独立手写 CSV 比对实际脚本输出的字节指纹。样本缺项、未知规则、自引用、未运行、进程非零退出仍留下可读文件、脚本哈希或参数不符、暂存内容改变、几何及参考指纹不符均被拒绝。
