# P3-10 方案版本与编辑失效

2026-11-11（Asia/Shanghai），Agent-F 提交 `REVIEW`。依据 V2.0 §6.6、§7.4、§8.6、[P3-10 任务](../../plans/04_TASKS/P3/P3-10.md)和[公共契约](../../plans/01_ARCHITECTURE/02_PUBLIC_CONTRACTS.md)。

`revise_plan` 从调用方指定的精确方案版本生成候选草稿。输入版本、方法版本、目标或关键选项变化时，沿原方案 ID 新增 `draft`。任务 ID 必须一致。使用相同方法版本且 `options=None` 时继承基线选项。显式传入的 `options` 是本次的完整选项集合。[版本服务](../../src/geopilot/plans/versioning.py)

SQLite `BEGIN IMMEDIATE` 将基线核对、分配版本和保存草稿放进同一写事务。最新确认版在编辑内容一致且无草稿问题时直接返回。与最新草稿内容一致的重复提交复用该版。旧基线产生不同内容时抛 `PlanVersionConflictError`，错误码为 `PLAN_VERSION_CONFLICT`，字段为 `version`。旧方案 JSON 与旧运行引用均可按原版本重读。验证使用 SQLite v1 的现有表。

草稿生成复用已登记单位转换校验显式量，同时保存用户原 `value` 和 `unit` 表达。实测确认快照的 `0.5 kilometer` 继承到新草稿的选项和步骤绑定，历史确认步骤中的规范参数仍为 500 米。[草稿生成修订](../../src/geopilot/plans/draft_builder.py)
