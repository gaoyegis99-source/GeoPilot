## 实现与接口

`geopilot.checks.process_checks.check_run_process(database_path, run_id, *, registry, qgis_bindings=None, python_implementations=None)` 返回 `tuple[ProcessCheckResult, ...]`。记录包含 `process` 阶段、规则名、步骤、字段、严重程度、判定、观察值及期望。读取使用 SQLite 只读事务和运行目录内的相对证据引用。

从精确确认版本和运行快照重建每步请求，用 `compile_step_request` 解析暂存资产和前序命名输出。逐项核对 SQLite 与磁盘请求、结果信封、工具版本、步骤位置及起止顺序。Python 使用进程日志和子进程清单核对实际参数文件、成果引用和环境，提供可信本机实现映射时同时比对实际脚本。支持旧日志中的运行目录内绝对请求路径。QGIS 使用真实计算 JSON 核对算法和运行环境，提供可信绑定时按逻辑端口及参数反查引擎实际值。

新增 `src/geopilot/checks/process_checks.py`、`tests/checks/test_process_checks.py`、本报告、JUnit 与实际运行证据。P4-15 将检查结果接入报告汇总。
