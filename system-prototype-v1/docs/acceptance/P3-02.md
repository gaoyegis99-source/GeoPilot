## 公共接口

`load_method_catalog(directory)` 读取指定本机目录下的 UTF-8 `.yaml` 和 `.yml` 文件，每份文件保存一个方法定义。`MethodCatalog.list()` 按 ID 和整数版本升序返回所有有效定义。`get(method_id, version=None)` 按精确版本查询，省略版本时取最高有效版本，未找到时抛出 `KeyError`。两种查询均返回独立副本。

`MethodCatalog.issues` 按路径顺序保存 `MethodLoadIssue(path, field, message)`。模型问题提供点分字段路径，文件读取和 YAML 文档问题以 `$` 表示，YAML 错误在可定位时附行列。加载器拒绝重复 YAML 键，包括合并后冲突的键。若多个有效文件声明相同 ID 和版本，该版本的所有副本均拒绝，每份文件的诊断列出冲突位置。同 ID 的其他有效版本仍可查询。根目录无法枚举时保留系统异常。
