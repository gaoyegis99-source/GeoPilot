# P6-11 转移矩阵与分区统计

Agent-B 建议 `REVIEW`。P6-10 已验收。正式方法 `land-use-change@1` 按 V2.0 §8.5、§10.4、§12.3.7 和附录 A.4 锁定七步，使用两期分类图层、分区和分析区，输出变化图斑、转移矩阵、分区统计。[设计报告](../../../docs/source/GeoPilot_产品需求规格与系统详细设计报告_V2.0.md) · [方法配置](../../config/methods/land-use-change.v1.yaml)

## 归属、筛选与总量

- 面积拆分用裁后的叠加片。质心和最大重叠按两个原始 ID 从完整投影成果重建唯一对应的裁前相交部件，再把裁后面积计到所选分区。已有 P6 规则处理边界、平局与未覆盖，未归属以 JSON `null` 保存。分区使用确认的等积米制 CRS，源 CRS 不同时复用 P2 重投影。
- 可选合并按来源类别与去向类别分组，再按正长度共边的连通部件合并。用合并后的面面积执行最小变化面积，等于阈值的变化面纳入统计。同类对角保留并标记 `is_change=false`。过滤前、保留和排除的面积及数量记录在 `change_report`。每行 `source_refs` 可回查全部叠加片和两期要素 ID、原始编码与时相。
- 类别轴由筛选前叠加片中出现的两期统一类别排序。矩阵使用正式图斑的实际几何面积，分区使用每个保留来源片在合并前的分区贡献。按类别对逐格核对分区与全局矩阵，并核对保留面积加过滤面积与叠加量。已登记的分区和未归属桶均可显示零值。
- `verify_transition_outputs` 可从 P4 成果规则重开叠加、变化图斑、归属记录、过滤报告与两份汇总，核对来源、几何、分类顺序、每格面积及总量。偏差提供 `field`、`observed` 和 `expected`。正式方法绑定的三项规则在运行报告分别保存完成状态与实测值。
