# P6-05 跨分区面积拆分

Agent-B 建议 `REVIEW`。P2-06 与 P6-01 已验收。依据 V2.0 §5.4 与 §8.5，`geopilot.gis.vector.boundary_assignment.split_area_by_zone(targets, zones)` 接收已经裁回统计范围的面目标和分区，返回目标 `source_feature_id` 到各分区 `source_feature_id` 平方米面积的映射。正面积未覆盖部分用 `None` 保存。两层须使用等价、实际的等积米制 CRS，实际范围通过 P2-06 验证。点等非面几何在计算前拒绝。

目标与每个分区的相交只记录正面积。两个分区的共有面与目标内部存在二维相交时拒绝，保留目标外的分区重叠以及零面积的共享边界。未覆盖面积从目标减去分区并集的几何求得。用 `math.fsum` 累计每个目标的面积，并以 `1e-6 m²` 绝对容差和 `1e-9` 相对容差检查守恒，处理投影坐标上的浮点求交与求和舍入。正面积重叠、未覆盖余量和各分区实际面积均按几何结果判断。
