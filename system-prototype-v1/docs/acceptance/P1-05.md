# P1-05 GeoTIFF 与 COG 元数据读取

2026-11-11，建议状态 `REVIEW`。依赖 P0-04、P0-06、P1-02 已验收。按 V2.0 §7.1、§12.3.2 和读取器契约实现 `geopilot.data.raster_reader.read_raster_metadata(path)`，返回 `RasterMetadata`。

入口只接受本机常规文件，将规范化的绝对 `Path` 交给 Rasterio，拒绝 `/vsi` 虚拟路径，以只读模式指定 GDAL `GTiff` 驱动。实测 GDAL 创建的 COG 读回时驱动为 `GTiff`，`IMAGE_STRUCTURE` 的 `LAYOUT` 为 `COG`。资产 `format` 保存实际读驱动。读取器返回宽、高、仿射六元组、坐标系单位的分辨率、排序后的范围、波段数及逐波段数据类型、名称、单位和 NoData。可精确匹配的 EPSG 写作 `EPSG:<code>`，自定义 CRS 保存 WKT。缺少 CRS 写作 `null` 并附 `CRS_UNKNOWN`，缺少 NoData 写作 `null`，非有限值按 `"nan"`、`"inf"` 和 `"-inf"` 保留。文件失败统一通过 `SourceReadError` 返回。 [Rasterio API](https://rasterio.readthedocs.io/en/stable/api/rasterio.html#rasterio.open) · [GDAL COG](https://gdal.org/en/stable/drivers/raster/cog.html)
